Common Properties​

These properties are available for both Vosk and Whisper engines.

model​

Description: Path to the speech recognition model.

Type: string Default:

  • Vosk: "/home/root/models/stt/vosk/vosk-model-small-en-us-0.15"
  • Whisper: "/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin"

For Vosk: Path to model directory containing am/, conf/, graph/, and ivector/ subdirectories.

For Whisper: Path to GGML model file (.bin format).

  • gst-launch
  • GObject Property
# Vosk
gst-launch-1.0 ... ! dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15 ! ...

# Whisper
gst-launch-1.0 ... ! dctstt model=/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin ! ...
// Vosk
g_object_set(G_OBJECT(element), "model",
    "/home/root/models/stt/vosk/vosk-model-small-en-us-0.15", NULL);

// Whisper
g_object_set(G_OBJECT(element), "model",
    "/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin", NULL);

Available Models:

Vosk:

  • Small: /home/root/models/stt/vosk/vosk-model-small-en-us-0.15 (~40MB, faster)
  • Large: /home/root/models/stt/vosk/vosk-model-en-us-0.22-lgraph (~1.8GB, more accurate)

Whisper:

  • Tiny: /home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin (~75MB, fastest)
  • Additional models can be installed from Whisper.cpp or Hugging Face

Vosk Engine Properties​

These properties are only available when using the Vosk engine (compile-time selection).

partials​

Description: Enable or disable partial recognition results during speech processing.

Type: boolean Default: true Availability: Vosk engine only

When enabled, the plugin sends intermediate recognition results as speech is being processed. When disabled, only final results (on speech pause) are sent.

note

This property is not available with the Whisper engine. Whisper only produces final results.

  • gst-launch
  • GObject Property
# Enable partial results (default)
gst-launch-1.0 ... ! dctstt partials=true ! ...

# Disable partial results (only finals)
gst-launch-1.0 ... ! dctstt partials=false ! ...
// Enable partial results
g_object_set(G_OBJECT(element), "partials", TRUE, NULL);

// Disable partial results
g_object_set(G_OBJECT(element), "partials", FALSE, NULL);

Use Cases:

  • Enabled: Real-time transcription, live captions, voice command confirmation
  • Disabled: Final transcription only, reduced output, simpler result handling

Whisper Engine Properties​

These properties are only available when using the Whisper engine (compile-time selection).

threads​

Description: Number of CPU threads to use for processing.

Type: int Range: 1 - 32 Default: 4

Higher thread counts can improve performance on multi-core systems but increase CPU usage. Adjust based on your hardware and performance requirements.

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt threads=8 ! ...
g_object_set(G_OBJECT(element), "threads", 8, NULL);

step-ms​

Description: Step size in milliseconds for audio processing window.

Type: int Range: 100 - 10000 ms Default: 3000 ms

Controls how often Whisper processes audio chunks. Smaller values give more frequent updates but higher CPU usage. Larger values reduce CPU usage but increase latency.

  • gst-launch
  • GObject Property
# Process every 2 seconds
gst-launch-1.0 ... ! dctstt step-ms=2000 ! ...

# Process every 5 seconds
gst-launch-1.0 ... ! dctstt step-ms=5000 ! ...
g_object_set(G_OBJECT(element), "step-ms", 2000, NULL);

length-ms​

Description: Length of audio buffer in milliseconds.

Type: int Range: 1000 - 30000 ms Default: 10000 ms

Defines the size of the audio buffer for processing. Larger buffers provide more context for better accuracy but increase latency. Should be >= step-ms.

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt length-ms=8000 ! ...
g_object_set(G_OBJECT(element), "length-ms", 8000, NULL);

use-vad​

Description: Enable Voice Activity Detection.

Type: boolean Default: false

When enabled, Whisper only processes audio when speech is detected, reducing CPU usage during silence periods. Recommended for continuous streaming applications.

  • gst-launch
  • GObject Property
# Enable VAD
gst-launch-1.0 ... ! dctstt use-vad=true ! ...
g_object_set(G_OBJECT(element), "use-vad", TRUE, NULL);

vad-threshold​

Description: VAD sensitivity threshold.

Type: float Range: 0.0 - 1.0 Default: 0.01

Lower values make VAD more sensitive (detect quieter speech), higher values require louder speech to trigger. Only effective when use-vad=true.

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt use-vad=true vad-threshold=0.02 ! ...
g_object_set(G_OBJECT(element), "use-vad", TRUE, NULL);
g_object_set(G_OBJECT(element), "vad-threshold", 0.02f, NULL);

TCP Backend Properties​

Available only when compiled with -Dcomm_backend=tcp.

tcp-port​

Description: TCP port number for the JSON server.

Type: int Range: 1 - 65535 Default: 9999

The plugin starts a TCP server on this port that clients can connect to for receiving recognition results in real-time.

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt tcp-port=8888 ! ...
g_object_set(G_OBJECT(element), "tcp-port", 8888, NULL);

Connect to TCP Server:

nc localhost 9999
# or
telnet localhost 9999

JSON Output Format:

// Vosk - Final result
{
  "text": "hello world"
}

// Vosk - Partial result (if partials=true)
{
  "partial": "hello wor"
}

// Whisper - Result
{
  "text": "hello world"
}

MQTT Backend Properties​

Available only when compiled with -Dcomm_backend=mqtt.

mqtt-broker​

Description: MQTT broker hostname or IP address.

Type: string Default: "localhost"

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt mqtt-broker=192.168.1.100 ! ...
g_object_set(G_OBJECT(element), "mqtt-broker", "192.168.1.100", NULL);

mqtt-port​

Description: MQTT broker port number.

Type: int Range: 1 - 65535 Default: 1883

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt mqtt-port=1883 ! ...
g_object_set(G_OBJECT(element), "mqtt-port", 1883, NULL);

mqtt-topic​

Description: MQTT topic to publish recognition results.

Type: string Default: "stt/results"

  • gst-launch
  • GObject Property
gst-launch-1.0 ... ! dctstt mqtt-topic=camera1/stt ! ...
g_object_set(G_OBJECT(element), "mqtt-topic", "camera1/stt", NULL);

Subscribe to MQTT Results:

mosquitto_sub -h localhost -t stt/results -v

Configuration Examples​

Vosk with TCP Backend​

gst-launch-1.0 alsasrc device=hw:1,0 ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    tcp-port=9999 \
    partials=true

Vosk with MQTT Backend​

gst-launch-1.0 alsasrc device=hw:1,0 ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    mqtt-broker=192.168.1.100 \
    mqtt-port=1883 \
    mqtt-topic=stt/vosk \
    partials=false

Whisper with TCP Backend (Real-time Optimized)​

gst-launch-1.0 alsasrc device=hw:1,0 ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=F32LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin \
    tcp-port=9999 \
    threads=4 \
    step-ms=2000 \
    use-vad=true \
    vad-threshold=0.01

Whisper with MQTT Backend (High Accuracy)​

gst-launch-1.0 alsasrc device=hw:1,0 ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=F32LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin \
    mqtt-broker=localhost \
    mqtt-topic=stt/whisper \
    threads=8 \
    step-ms=3000 \
    length-ms=10000

From Audio File (Batch Processing)​

Vosk:

gst-launch-1.0 filesrc location=/home/root/models/stt/test/sample.wav ! \
  wavparse ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    partials=false

Whisper:

gst-launch-1.0 filesrc location=/home/root/models/stt/test/sample.wav ! \
  wavparse ! \
  audioconvert ! \
  audioresample ! \
  audio/x-raw,format=F32LE,channels=1,rate=16000 ! \
  dctstt model=/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin \
    threads=8

Performance Tuning Guidelines​

Whisper Engine Tuning​

For Real-time Applications:

threads=4 step-ms=2000 use-vad=true

For High Accuracy:

threads=8 length-ms=10000 step-ms=3000

For Low CPU Usage:

threads=2 use-vad=true vad-threshold=0.02

Vosk Engine Tuning​

For Low Latency:

  • Use partials=true for immediate feedback
  • Use small model for faster processing

For High Accuracy:

  • Use large model (vosk-model-en-us-0.22-lgraph)
  • Set partials=false for cleaner final results

Querying Properties at Runtime​

Using gst-inspect-1.0​

# List all properties
gst-inspect-1.0 dctstt

Using GObject API​

// Query model path
gchar *model_path;
g_object_get(G_OBJECT(element), "model", &model_path, NULL);
g_print("Model: %s\n", model_path);
g_free(model_path);

// Query threads (Whisper only)
gint threads;
g_object_get(G_OBJECT(element), "threads", &threads, NULL);
g_print("Threads: %d\n", threads);

// Query partials (Vosk only)
gboolean partials;
g_object_get(G_OBJECT(element), "partials", &partials, NULL);
g_print("Partials: %s\n", partials ? "enabled" : "disabled");
