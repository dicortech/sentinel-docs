Usage Examples

This page provides complete, ready-to-use examples of the dctstt element with both Vosk and Whisper engines in various scenarios.

Vosk Engine Examples​

Basic Speech Recognition​

From Microphone (USB)​

# Basic USB microphone
gst-launch-1.0 alsasrc device=hw:1,0 ! \
    audioconvert ! \
    audioresample ! \
    audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
    dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15

From DMIC​

# Digital microphone (DMIC)
gst-launch-1.0 alsasrc device=hw:0,2 ! \
    audioconvert ! \
    audioresample ! \
    audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
    dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15

From Audio File​

# WAV file
gst-launch-1.0 filesrc location=test.wav ! \
    wavparse ! \
    audioconvert ! \
    audioresample ! \
    audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
    dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15

Common Parameters​

Vosk Engine​

  • model= - Path to model directory
  • partials=true/false - Send partial results
  • tcp-port=9999 (TCP backend only)
  • mqtt-broker=localhost (MQTT backend only)
  • mqtt-port=1883 (MQTT backend only)
  • mqtt-topic=topic (MQTT backend only)

Whisper Engine​

  • model= - Path to GGML model file
  • threads=4 - Number of threads
  • step-ms=3000 - Step size in milliseconds
  • length-ms=10000 - Buffer length in milliseconds
  • use-vad=true/false - Enable VAD
  • vad-threshold=0.01 - VAD sensitivity
  • tcp-port=9999 (TCP backend only)
  • mqtt-broker=localhost (MQTT backend only)
  • mqtt-port=1883 (MQTT backend only)
  • mqtt-topic=topic (MQTT backend only)

Debugging and Testing​

Enable GStreamer Debug Output​

# Level 3: Info messages
GST_DEBUG=dctstt:3 gst-launch-1.0 ... ! dctstt ...

# Level 4: Debug messages
GST_DEBUG=dctstt:4 gst-launch-1.0 ... ! dctstt ...

# Level 5: Trace messages
GST_DEBUG=dctstt:5 gst-launch-1.0 ... ! dctstt ...

# All GStreamer debug output
GST_DEBUG=*:3 gst-launch-1.0 ... ! dctstt ...

List ALSA Devices​

arecord -L

Test Recording​

# Record 5 seconds
arecord -d 5 -f S16_LE -r 16000 -c 1 test.wav

# Play back
aplay test.wav

Common Issues and Solutions​

No Recognition Output​

Check that:

  1. Microphone is working: arecord -d 5 test.wav && aplay test.wav
  2. Model path is correct: ls models/vosk_model or ls models/ggml-model-q8_0.bin
  3. Audio format is correct:
    • Vosk: S16LE, mono, 16kHz
    • Whisper: F32LE, mono, 16kHz

Poor Recognition Accuracy​

Vosk:

  • Use a larger model for better accuracy
  • Ensure clean audio input (reduce background noise)
  • Update grammar file with specific vocabulary

Whisper:

  • Use a larger model (base → small → medium)
  • Adjust threads for better performance
  • Enable VAD with use-vad=true
  • Adjust step-ms and length-ms for your use case

High CPU Usage​

Vosk:

  • Use smaller model (vosk-model-small-*)
  • Disable partial results (partials=false)

Whisper:

  • Use smaller model (tiny or base)
  • Reduce thread count (threads=2)
  • Enable VAD (use-vad=true)
  • Increase step-ms value

Batch Processing​

Transcribe Multiple Files​

#!/bin/bash

# Using Vosk
for file in *.wav; do
    echo "Processing: $file"
    gst-launch-1.0 filesrc location="$file" ! \
        wavparse ! \
        audioconvert ! \
        audioresample ! \
        audio/x-raw,format=S16LE,channels=1,rate=16000 ! \
        dctstt model=/home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
            tcp-port=9999 > "${file%.wav}.txt"
done

# Using Whisper
for file in *.wav; do
    echo "Processing: $file"
    gst-launch-1.0 filesrc location="$file" ! \
        wavparse ! \
        audioconvert ! \
        audioresample ! \
        audio/x-raw,format=F32LE,channels=1,rate=16000 ! \
        dctstt model=/home/root/models/stt/whisper/ggml-tiny.en-q5_1.bin \
            tcp-port=9999 > "${file%.wav}.txt"
done
