Plugin Library

The Gstreamer plugin can be configured by changing its properties. Gstreamer provides a framework for achieving this, by using the g_object_set functions. We have also provided an API wrapper layer for specific use cases, which runs on top of the Gstreamer's APIs to achieve the same result.

The API definitions and their test codes can be found in the api/ directories:

inc/                   # Header files
├── gst/               # GStreamer layer (plugin interface)
├── mach/              # Machine layer (rendering backends)
├── comm/              # Communication layer (MQTT)
└── api/               # API layer (C interface)

src/                   # Source files
├── gst/               # GStreamer implementation
├── mach/              # Machine implementations
├── comm/              # Communication implementation
└── api/               # API implementation

Usage Flow​

To use the plugin library you will need to follow the below sequence of operations.

Step 1: Pipeline Initialization​

Initialize a gstreamer pipeline with this plugin.

#include <apidctoverlay.h>

GstElement *pipeline, *overlay;

// Initialize
gst_init(&argc, &argv);
pipeline = gst_parse_launch("v4l2src ! videoconvert ! video/x-raw,format=BGR ! dctoverlay name=overlay ! ...", NULL);
note

The plugin must have a name associated with it, which we will use to initialize the plugin api layer.

Step 2: Plugin Initialization​

Once the pipeline is initialized successfully, call the plugin initialization function to get the plugin element object.

  • With API
  • GST API
// Initialize
overlay = api_dctoverlay_init(pipeline, "overlay");
// Initialize
overlay = gst_bin_get_by_name(pipeline, "overlay");

Step 3: Plugin Configuration​

Once the initialization is done, you can use the apis as needed.

  • With API
  • GST API
// Configure MQTT
api_dctoverlay_set_mqtt_host(overlay, "localhost");
api_dctoverlay_set_mqtt_topic(overlay, "detections");

// Configure box styling
api_dctoverlay_set_box_color(overlay, 0, 255, 0);  // Green
api_dctoverlay_set_box_thickness(overlay, 2);

// Configure font styling
api_dctoverlay_set_font_scale(overlay, 0.6);
api_dctoverlay_set_font_color(overlay, 255, 255, 0);  // Yellow
api_dctoverlay_set_font_thickness(overlay, 2);

// Configure label background
api_dctoverlay_set_label_background(overlay, true);
api_dctoverlay_set_label_bg_color(overlay, 0, 0, 0);  // Black
api_dctoverlay_set_label_bg_alpha(overlay, 0.7);

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);
// Configure using hex colors (easier)
g_object_set(overlay,
            "mqtt-host"             , "localhost",
            "mqtt-topic"            , "detections",
            "bbox-colour"           , "#00FF00",  // Green boxes
            "bbox-thickness"        , 2,
            "font-scale"            , 0.6,
            "label-colour"          , "#FFFF00",  // Yellow text
            "font-thickness"        , 2,
            "draw-label-background" , TRUE,
            "label-bg-colour"       , "#000000",  // Black background
            "label-bg-alpha"        , 0.7,
            NULL);

// Or configure using RGB components
g_object_set(overlay,
            "mqtt-host"             , "localhost",
            "mqtt-topic"            , "detections",
            "bbox-colour-r"         , 0,
            "bbox-colour-g"         , 255,
            "bbox-colour-b"         , 0,
            "bbox-thickness"        , 2,
            "font-scale"            , 0.6,
            "font-thickness"        , 2,
            "draw-label-background" , TRUE,
            "label-bg-colour-r"     , 0,
            "label-bg-colour-g"     , 0,
            "label-bg-colour-b"     , 0,
            "label-bg-alpha"        , 0.7,
            NULL);

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);

Functions​

These functions provide a C interface for controlling overlay rendering from GStreamer pipelines.

api_dctoverlay_init​

Initialize and retrieve the dctoverlay element from a GStreamer pipeline.

GstElement* api_dctoverlay_init(GstElement *pipeline, const char *element_name);

Parameters:

  • pipeline - GstElement pipeline containing the dctoverlay element
  • element_name - Name of the dctoverlay element in the pipeline

Returns:

  • Pointer to dctoverlay element on success
  • NULL on failure
Memory Management

The caller is responsible for unreferencing the returned element using gst_object_unref() when done.

Example:

GstElement *pipeline = ...; // Your pipeline
GstElement *overlay = api_dctoverlay_init(pipeline, "overlay");
if (overlay) {
    // Use the overlay element
    gst_object_unref(overlay);
}

MQTT Configuration Functions​

api_dctoverlay_set_mqtt_host​

Set the MQTT broker hostname or IP address.

void api_dctoverlay_set_mqtt_host(GstElement *overlay, const char *host);

Parameters:

  • overlay - dctoverlay GstElement
  • host - MQTT broker host address

Example:

api_dctoverlay_set_mqtt_host(overlay, "192.168.1.100");

api_dctoverlay_set_mqtt_port​

Set the MQTT broker port number.

void api_dctoverlay_set_mqtt_port(GstElement *overlay, int port);

Parameters:

  • overlay - dctoverlay GstElement
  • port - MQTT broker port (1-65535)

Example:

api_dctoverlay_set_mqtt_port(overlay, 1883);

api_dctoverlay_set_mqtt_topic​

Set the MQTT topic to subscribe for detection messages.

void api_dctoverlay_set_mqtt_topic(GstElement *overlay, const char *topic);

Parameters:

  • overlay - dctoverlay GstElement
  • topic - MQTT topic for detections

Example:

api_dctoverlay_set_mqtt_topic(overlay, "detections");

Box Styling Functions​

api_dctoverlay_set_box_color​

Set the bounding box color in RGB components.

void api_dctoverlay_set_box_color(GstElement *overlay, int r, int g, int b);

Parameters:

  • overlay - dctoverlay GstElement
  • r - Red component (0-255)
  • g - Green component (0-255)
  • b - Blue component (0-255)

Example:

// Green boxes
api_dctoverlay_set_box_color(overlay, 0, 255, 0);

// Yellow boxes
api_dctoverlay_set_box_color(overlay, 255, 255, 0);

api_dctoverlay_set_box_thickness​

Set the bounding box border thickness.

void api_dctoverlay_set_box_thickness(GstElement *overlay, int thickness);

Parameters:

  • overlay - dctoverlay GstElement
  • thickness - Thickness in pixels (1-50)

Example:

api_dctoverlay_set_box_thickness(overlay, 2);

Font Styling Functions​

api_dctoverlay_set_font_type​

Set the OpenCV font type for label text.

void api_dctoverlay_set_font_type(GstElement *overlay, int font_type);

Parameters:

  • overlay - dctoverlay GstElement
  • font_type - OpenCV font type (0-7)

Font Types:

  • 0: SIMPLEX
  • 1: PLAIN
  • 2: DUPLEX
  • 3: COMPLEX
  • 4: TRIPLEX
  • 5: COMPLEX_SMALL
  • 6: SCRIPT_SIMPLEX
  • 7: SCRIPT_COMPLEX

Example:

api_dctoverlay_set_font_type(overlay, 0);  // SIMPLEX

api_dctoverlay_set_font_scale​

Set the font size scale factor.

void api_dctoverlay_set_font_scale(GstElement *overlay, double scale);

Parameters:

  • overlay - dctoverlay GstElement
  • scale - Font size scale factor (0.1-10.0)

Example:

api_dctoverlay_set_font_scale(overlay, 0.6);

api_dctoverlay_set_font_color​

Set the font color in RGB components.

void api_dctoverlay_set_font_color(GstElement *overlay, int r, int g, int b);

Parameters:

  • overlay - dctoverlay GstElement
  • r - Red component (0-255)
  • g - Green component (0-255)
  • b - Blue component (0-255)

Example:

// Yellow text

api_dctoverlay_set_font_thickness​

Set the font thickness.

Parameters:

  • overlay - dctoverlay GstElement
  • thickness - Font thickness in pixels (1-10)

Example:

api_dctoverlay_set_font_thickness(overlay, 2);

Usage Example​

Here's a complete example demonstrating the API usage:

#include "apidctoverlay.h"

int main(int argc, char *argv[])
{
    GstElement *pipeline, *overlay;

    // Initialize pipeline
    gst_init(&argc, &argv);
    pipeline = gst_parse_launch(
        "v4l2src device=/dev/video8 ! videoconvert ! "
        "video/x-raw,format=BGR ! "
        "dctoverlay name=overlay ! "
        "videoconvert ! autovideosink",
        NULL);

    // Get overlay element
    overlay = api_dctoverlay_init(pipeline, "overlay");
    if (!overlay) {
        fprintf(stderr, "Failed to initialize overlay element\n");
        return -1;
    }

    // Configure MQTT
    api_dctoverlay_set_mqtt_host(overlay, "localhost");
    api_dctoverlay_set_mqtt_topic(overlay, "detections");

    // Configure box styling (green boxes)
    api_dctoverlay_set_box_color(overlay, 0, 255, 0);
    api_dctoverlay_set_box_thickness(overlay, 2);

    // Configure font styling (yellow text)
    api_dctoverlay_set_font_scale(overlay, 0.6);
    api_dctoverlay_set_font_color(overlay, 255, 255, 0);
    api_dctoverlay_set_font_thickness(overlay, 2);

    // Configure label background (black, semi-transparent)
    api_dctoverlay_set_label_background(overlay, true);
    api_dctoverlay_set_label_bg_color(overlay, 0, 0, 0);
    api_dctoverlay_set_label_bg_alpha(overlay, 0.7);

    // Configure label position (top-left)
    api_dctoverlay_set_label_position(overlay, 0);

    // Configure confidence display
    api_dctoverlay_set_show_confidence(overlay, true);
    api_dctoverlay_set_confidence_decimals(overlay, 2);

    // Configure ROI (optional)
    g_object_set(overlay,
                 "enable-roi", TRUE,
                 "roi-x", 100,
                 "roi-y", 100,
                 "roi-width", 400,
                 "roi-height", 300,
                 NULL);

    // Start pipeline
    gst_element_set_state(pipeline, GST_STATE_PLAYING);

    // Run main loop...

    // Cleanup
    gst_object_unref(overlay);
    gst_object_unref(pipeline);

    return 0;
}

MQTT Message Format​

The plugin expects detection data in the following JSON format:

{
  "detections": [
    {
      "bbox": {
        "x": 100,
        "y": 50,
        "width": 200,
        "height": 150
      },
      "label": "person",
      "confidence": 0.95,
      "class_id": 0
    }
  ]
}

Fields:

  • bbox: Bounding box coordinates (x, y, width, height)
  • label: Object class label (string)
  • confidence: Detection confidence (0.0-1.0)
  • class_id: Object class ID (integer, optional for filtering)
