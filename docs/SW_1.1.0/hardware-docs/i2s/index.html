I2S

Let's verify I2S.

Getting Started​

Sentinel SOM_SL1680_Mk1 supports multi-channel digital audio output via I²S, with configurations ranging from standard 2-channel stereo (I²S/PCM) to 8-channel high-performance audio (via TDM). For validation, we interfaced the SoC with a PCM5100 DAC and tested 2-channel I²S output.

I2S Lines on 40 pin header​

I2S1 Pins​

Pin NoName
14I2S1_DATA0_LV
15I2S1_BCLK_LV
16I2S1_MCLK_LV
17I2S1_LRCLK_LV

I2S2 Pins​

Pin NoName
18I2S2_LRCLK_LV
20I2S2_BCLK_LV
21I2S2_DATA0_LV
note

The I2S1 is configured as playback device and I2S2 is configured as capture device.

Testing I2S1​

Connection diagram​

Connect the PCM5100 DAC to I2S1.

After connecting the DAC to the I2S lines follow the steps provided.

Steps​

  1. Identify the soc-i2so1 device number from aplay -l

  1. Copy a wave file to the device using USB-storage device or tftp.

  2. Play the audio file to the playback device and verify the audio is audible through an earphone connected to the 3.5mm jack on the PCM5100 board.

aplay -D plughw:0,0 path/test.wav -vv

Testing I2S2​

Connection diagram​

Connect the I2S1 lines to I2S2 for loopback testing the I2S2.

Please follow the steps after making the connections proper:

Steps​

  1. Identify the soc-i2si2 device number from arecord -l

  1. Copy a wave file to the device using USB-storage device or tftp.

  2. Play the audio file to the playback device soc-i2so1.

aplay -D plughw:0,0 path/test.wav -vv
  1. Record the capture device soc-i2si2.
arecord -D hw:0,2 -f S16_LE -r 44100 -c 2 -d 40 capture.wav &
  1. Play the audio file to the playback device soc-i2so1.
aplay -D plughw:0,0 path/test.wav -vv
  1. Verify the capture.wav file captured using I2S1 by following I2S1 testing steps or copying the file to a PC with Audacity.
