Plugin Library

The Gstreamer plugin can be configured by changing its properties. Gstreamer provides a framework for achieving this, by using the g_object_set functions. We have also provided an API wrapper layer for specific use cases, which runs on top of the Gstreamer's APIs to achieve the same result.

The API definitions and their test codes can be found in the api/ directories:

inc/                   # Header files
├── gst/               # GStreamer layer (plugin interface)
├── mach/              # Machine layer (processing & conversion)
├── comm/              # Communication layer (MQTT support)
└── api/               # API layer (C interface)

src/                   # Source files
├── gst/               # GStreamer implementation
├── mach/              # Machine implementations (generic, hw, etc.)
├── comm/              # Communication layer
└── api/               # API implementation

test/                  # Test applications
├── gst/               # GStreamer-based user interactive tests
└── api/               # API-based user interactive tests

Usage Flow​

To use the plugin library you will need to follow the below sequence of operations.

Step 1: Pipeline Initialization​

Initialize a gstreamer pipeline with this plugin.

#include <apidctvrecord.h>

GstElement *pipeline, *vrecord;

// Initialize
gst_init(&argc, &argv);
pipeline = gst_parse_launch("videotestsrc ! x264enc ! h264parse ! dctvrecord name=rec ! fakesink", NULL);
note

The plugin must have a name associated with it, which we will use to initialize the plugin api layer.

Step 2: Plugin Initialization​

Once the pipeline is initialized successfully, call the plugin initialization function to get the plugin element object.

  • With API
  • GST API
// Initialize
vrecord = api_dctvrecord_init(pipeline, "rec");
// Initialize
vrecord = gst_bin_get_by_name(pipeline, "rec");

Step 3: Plugin Configuration​

Once the initialization is done, you can use the apis as needed.

  • With API
  • GST API
// Configure for manual mode
api_dctvrecord_set_mode(vrecord, DCTVRECORD_MODE_MANUAL);
api_dctvrecord_set_location(vrecord, "/tmp/videos");
api_dctvrecord_set_prefix(vrecord, "camera1");

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);

// Start recording
api_dctvrecord_set_recording(vrecord, true);

// ... record for some time ...

// Stop recording
api_dctvrecord_set_recording(vrecord, false);
// Configure for manual mode
g_object_set(vrecord,
            "mode"     , 0,
            "location" , "/tmp/videos",
            "prefix"   , "camera1",
            NULL);

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);

// Start recording
g_object_set(vrecord, "recording", true, NULL);

// ... record for some time ...

// Stop recording
g_object_set(vrecord, "recording", false, NULL);

Custom DataTypes​

DCTVRecordMode​

Defines the recording mode for the dctvrecord element.

typedef enum {
    DCTVRECORD_MODE_MANUAL = 0,    // Manual recording mode
    DCTVRECORD_MODE_AUTO = 1       // Automatic recording mode
} DCTVRecordMode;
ValueDescription
DCTVRECORD_MODE_MANUALUser controls recording via recording property or API
DCTVRECORD_MODE_AUTOAutomatic recording based on MQTT messages

Functions​

These functions provide a C interface for controlling video recording from GStreamer pipelines. It supports both manual and automatic recording modes with MQTT-based event-driven control.

api_dctvrecord_init​

Initialize and retrieve the dctvrecord element from a GStreamer pipeline.

GstElement* api_dctvrecord_init(GstElement *pipeline, const char *element_name);

Parameters:

  • pipeline - GstElement pipeline containing the dctvrecord element
  • element_name - Name of the dctvrecord element in the pipeline

Returns:

  • Pointer to dctvrecord element on success
  • NULL on failure
Memory Management

The caller is responsible for deinitializing the returned element using api_dctvrecord_deinit() when done.

Example:

GstElement *pipeline = ...; // Your pipeline
GstElement *vrecord = api_dctvrecord_init(pipeline, "myrecorder");
if (vrecord) {
    // Use the vrecord element
    api_dctvrecord_deinit(vrecord);
}

api_dctvrecord_deinit​

Deinitialize and cleanup the dctvrecord element.

void api_dctvrecord_deinit(GstElement *element);

Parameters:

  • element - dctvrecord GstElement to deinitialize

Returns:

  • void (no return value)
note

This function properly cleans up and unreferences the dctvrecord element.

Example:

GstElement *vrecord = api_dctvrecord_init(pipeline, "myrecorder");
if (vrecord) {
    // Configure and use the element
    api_dctvrecord_set_location(vrecord, "/tmp/videos");

    // ... do work ...

    // Cleanup
    api_dctvrecord_deinit(vrecord);
}

api_dctvrecord_set_mode​

Set the recording mode (manual or automatic).

bool api_dctvrecord_set_mode(GstElement *element, DCTVRecordMode mode);

Parameters:

  • element - dctvrecord GstElement
  • mode - Recording mode (DCTVRECORD_MODE_MANUAL or DCTVRECORD_MODE_AUTO)

Returns:

  • true on success
  • false on failure

Example:

// Set to manual mode
api_dctvrecord_set_mode(vrecord, DCTVRECORD_MODE_MANUAL);

// Set to automatic mode
api_dctvrecord_set_mode(vrecord, DCTVRECORD_MODE_AUTO);

api_dctvrecord_set_location​

Set the directory where recorded MP4 files will be saved.

bool api_dctvrecord_set_location(GstElement *element, const char *location);

Parameters:

  • element - dctvrecord GstElement
  • location - Directory path for saving MP4 files

Returns:

  • true on success
  • false on failure
info

Filenames are automatically generated with timestamps in the format: prefix_YYYY_MM_DD_HH_MM_SS_MSS.mp4 in the respective date directory under location

Example:

api_dctvrecord_set_location(vrecord, "/home/user/recordings");
recordings/                                 # Directory specified in the location property
└── YYYY_MM_DD/                             # Date-wise subfolder
    └── prefix_YYYY_MM_DD_HH_MM_SS_MSS.mp4

api_dctvrecord_set_prefix​

Set a prefix for recorded video filenames.

bool api_dctvrecord_set_prefix(GstElement *element, const char *prefix);

Parameters:

  • element - dctvrecord GstElement
  • prefix - Prefix string for filenames (optional, can be NULL)

Returns:

  • true on success
  • false on failure

Filename Format:

  • With prefix: <prefix>_YYYY_MM_DD_HH_MM_SS_MSS.mp4
  • Without prefix: YYYY_MM_DD_HH_MM_SS_MSS.mp4

Example:

api_dctvrecord_set_prefix(vrecord, "camera1");
// Results in: camera1_2025_10_13_14_30_25_123.mp4

api_dctvrecord_set_recording​

Start or stop recording (MANUAL mode only).

bool api_dctvrecord_set_recording(GstElement *element, bool recording);

Parameters:

  • element - dctvrecord GstElement
  • recording - true to start recording, false to stop

Returns:

  • true on success
  • false on failure
Mode Requirement

This function only works in DCTVRECORD_MODE_MANUAL. In AUTO mode, recording is controlled automatically by MQTT messages.

Example:

// Ensure manual mode is set
api_dctvrecord_set_mode(vrecord, DCTVRECORD_MODE_MANUAL);

// Start recording
api_dctvrecord_set_recording(vrecord, true);

// Stop recording
api_dctvrecord_set_recording(vrecord, false);

api_dctvrecord_set_en​

Enable recording with location and prefix in one call.

bool api_dctvrecord_set_en(GstElement *element, const char *location, const char *prefix);

Parameters:

  • element - dctvrecord GstElement
  • location - Directory path for saving files
  • prefix - Filename prefix (can be NULL)

Returns:

  • true on success
  • false on failure

Example:

// Start recording with location and prefix
api_dctvrecord_set_en(vrecord, "/tmp/videos", "cam1");

  • true on success

api_dctvrecord_set_auto_enable​

Enable or disable automatic recording in AUTO mode.

bool api_dctvrecord_set_auto_enable(GstElement *element, bool enable);

Parameters:

  • element - dctvrecord GstElement
  • enable - true to enable auto recording, false to disable

Returns:

  • true on success
  • false on failure
note

Only effective in AUTO mode. When enabled, connects to MQTT broker and starts monitoring for detection messages.

Example:

// Enable automatic recording
api_dctvrecord_set_auto_enable(vrecord, true);

// Disable automatic recording
api_dctvrecord_set_auto_enable(vrecord, false);

Retrieve the current save directory location.

char* api_dctvrecord_get_location(GstElement *element);

Parameters:

Retrieve the current recording state.

bool api_dctvrecord_get_recording(GstElement *element, bool *recording);

api_dctvrecord_set_host​

Set the MQTT broker host address (AUTO mode only).

bool api_dctvrecord_set_host(GstElement *element, const char *host);

Parameters:

  • element - dctvrecord GstElement
  • host - Host address (e.g., "localhost", "192.168.1.100")

Returns:

  • true on success
  • false on failure
note

This property applies to all communication protocols (MQTT, TCP, Kafka, etc.). Currently only MQTT is supported. Default value is "localhost".

Example:

// Set MQTT broker host to remote server
api_dctvrecord_set_host(vrecord, "192.168.1.100");

api_dctvrecord_set_det_timeout​

Set the detection timeout for automatic recording stop (AUTO mode only).

bool api_dctvrecord_set_det_timeout(GstElement *element, double det_timeout);

Parameters:

  • element - dctvrecord GstElement
  • det_timeout - Detection timeout in seconds (e.g., 10.0)

Returns:

  • true on success
  • false on failure
note

Only effective in AUTO mode. If no detections are received for this duration, recording automatically stops.

Example:

// Set timeout to 5 seconds
api_dctvrecord_set_det_timeout(vrecord, 5.0);

// Recording will stop 5 seconds after the last detection message

api_dctvrecord_get_det_timeout​

Retrieve the current detection timeout.

bool api_dctvrecord_get_det_timeout(GstElement *element, double *det_timeout);

Parameters:

  • element - dctvrecord GstElement
  • det_timeout - Pointer to store the current detection timeout in seconds

Returns:

  • true on success
  • false on failure

Example:

double timeout;
if (api_dctvrecord_get_det_timeout(vrecord, &timeout)) {
    printf("Detection timeout: %.1f seconds\n", timeout);
}

Usage Example​

Here's a complete example demonstrating the API usage:

#include "apidctvrecord.h"

int main(int argc, char *argv[])
{
    GstElement *pipeline, *vrecord;

    // Initialize GStreamer
    gst_init(&argc, &argv);

    // Create pipeline
    pipeline = gst_parse_launch(
        "videotestsrc ! "
        "video/x-raw,format=I420,width=640,height=480,framerate=30/1 ! "
        "x264enc tune=zerolatency bitrate=2000 ! "
        "h264parse config-interval=-1 ! "
        "video/x-h264,stream-format=avc,alignment=au ! "
        "dctvrecord name=myrecorder ! "
        "fakesink",
        NULL);

    if (!pipeline) {
        fprintf(stderr, "Failed to create pipeline\n");
        return -1;
    }

    // Get vrecord element
    vrecord = api_dctvrecord_init(pipeline, "myrecorder");
    if (!vrecord) {
        fprintf(stderr, "Failed to initialize vrecord element\n");
        return -1;
    }

    // Configure for automatic recording
    api_dctvrecord_set_mode(vrecord, DCTVRECORD_MODE_AUTO);
    api_dctvrecord_set_location(vrecord, "/tmp/recordings");
    api_dctvrecord_set_prefix(vrecord, "test");
    api_dctvrecord_set_host(vrecord, "192.168.1.100");
    api_dctvrecord_set_port(vrecord, 1883);
    api_dctvrecord_set_mqtt_topic(vrecord, "detections/camera1");
    api_dctvrecord_set_det_timeout(vrecord, 10.0);
    api_dctvrecord_set_auto_enable(vrecord, true);

    // Start pipeline
    gst_element_set_state(pipeline, GST_STATE_PLAYING);

    // Recording starts automatically when detection messages are received
    printf("Waiting for MQTT detection messages...\n");

    // Run for 60 seconds
    sleep(60);

    // Disable auto recording
    printf("Disabling auto recording...\n");
    api_dctvrecord_set_auto_enable(vrecord, false);

    // Cleanup
    gst_element_set_state(pipeline, GST_STATE_NULL);
    api_dctvrecord_deinit(vrecord);
    gst_object_unref(pipeline);

    return 0;
}
