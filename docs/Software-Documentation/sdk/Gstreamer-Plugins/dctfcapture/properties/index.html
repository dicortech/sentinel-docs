Properties

PropertyTypeDescriptionDefault
locationstringDirectory path where JPEG images are saved/tmp
prefixstringFilename prefix (optional)NULL
capturebooleanTrigger next frame capture (manual mode)false
modeintCapture mode: 0=Manual, 1=Periodic, 2=AUTO0 (Manual)
time-perioduintCapture interval in seconds (periodic mode)5
mqtt-topicstringMQTT topic for object detection (AUTO mode)NULL
mqtt-hoststringMQTT broker hostname or IP address (AUTO mode)localhost
mqtt-portuintMQTT broker port number (AUTO mode)1883
time-skipuintMinimum time between captures in ms (AUTO mode)500

Property Details​

location​

Specifies the directory path where the images needs to be saved.

  • Type: String
  • Default: NULL
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctfcapture location=/tmp/ ...
api_dctfcapture_set_location(<element_object>, <dir_location>);
g_object_set(<element_object>, "location", <dir_location>, NULL);

prefix​

Specifies the prefix that needs to be prepended to the file names.

  • Type: String
  • Default: NULL
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctfcapture prefix=CAM1 ...
api_dctfcapture_set_prefix(<element_object>, <prefix_name>);
g_object_set(<element_object>, "prefix", <prefix_name>, NULL);

The files will be saved as follows:

  • With prefix: <PREFIX>_YYYY_MM_DD_HH_MM_SS_MSS.jpg
  • Without prefix: YYYY_MM_DD_HH_MM_SS_MSS.jpg

capture​

Writing true to this property will save the frame as jpeg. Once the frame is captured, the value will be set to false and it needs to be set to true again to capture the next frame.

  • Type: Boolean
  • Default: false
  • Access: Read
note

Ensure that the mode is set to 0 (Manual) to use this property.

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctfcapture capture=true ...
api_dctfcapture_trigger(<element_object>);
g_object_set(<element_object>, "capture", true, NULL);

mode​

Specifies the capture mode. This plugin can capture frames in 3 modes:

  • Manual (0): User manually triggers frame capture via API

  • Periodic (1): Automatic capture at specified time intervals

  • AUTO (2): Event-driven capture based on MQTT object detection messages

  • Type: Integer (0=Manual, 1=Periodic, 2=AUTO)

  • Default: 0 (Manual)

  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
# Manual mode
gst-launch-1.0 ... ! dctfcapture mode=0 ...

# Periodic mode
gst-launch-1.0 ... ! dctfcapture mode=1 ...

# AUTO mode
gst-launch-1.0 ... ! dctfcapture mode=2 ...
// Manual mode
api_dctfcapture_set_mode(<element_object>, DCTFCAPTURE_MODE_MANUAL);

// Periodic mode
api_dctfcapture_set_mode(<element_object>, DCTFCAPTURE_MODE_PERIODIC);

// AUTO mode
api_dctfcapture_set_mode(<element_object>, DCTFCAPTURE_MODE_AUTO);
// Manual mode
g_object_set(<element_object>, "mode", 0, NULL);

// Periodic mode
g_object_set(<element_object>, "mode", 1, NULL);

// AUTO mode
g_object_set(<element_object>, "mode", 2, NULL);

time-period​

Specifies the time period in seconds to be used with periodic mode. The time period can range from 1 to 3600 seconds.

  • Type: Integer (Unsigned)
  • Default: 5
  • Range: 1-3600 seconds
  • Access: Read/Write
note

Only effective in PERIODIC mode (mode=1).

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctfcapture time-period=5 ...
api_dctfcapture_set_time_period(<element_object>, <time_period>);
g_object_set(<element_object>, "time-period", <time_period>, NULL);

mqtt-topic​

Specifies the MQTT topic to subscribe for object detection messages in AUTO mode.

  • Type: String
  • Default: NULL
  • Access: Read/Write
note

Only effective in AUTO mode (mode=2).

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctfcapture mode=2 mqtt-topic=object/detection ...
api_dctfcapture_set_mqtt_topic(<element_object>, "object/detection");
g_object_set(<element_object>, "mqtt-topic", "object/detection", NULL);

mqtt-host​

Specifies the MQTT broker hostname or IP address for AUTO mode. Supports both local and remote brokers.

  • Type: String
  • Default: "localhost"
  • Access: Read/Write
note

Only effective in AUTO mode (mode=2). If already connected, will automatically reconnect with the new host.

Usage:

  • Bash
  • With API
  • GST API
# Connect to remote broker
gst-launch-1.0 ... ! dctfcapture mode=2 mqtt-host=192.168.1.100 ...

# Connect to localhost (default)
gst-launch-1.0 ... ! dctfcapture mode=2 mqtt-host=localhost ...
// Connect to remote broker
api_dctfcapture_set_mqtt_host(<element_object>, "192.168.1.100");

// Connect to localhost
api_dctfcapture_set_mqtt_host(<element_object>, "localhost");
// Connect to remote broker
g_object_set(<element_object>, "mqtt-host", "192.168.1.100", NULL);

// Connect to localhost
g_object_set(<element_object>, "mqtt-host", "localhost", NULL);

mqtt-port​

Specifies the MQTT broker port number for AUTO mode.

  • Type: Integer (Unsigned)
  • Default: 1883
  • Range: 1-65535
  • Access: Read/Write
note

Only effective in AUTO mode (mode=2). If already connected, will automatically reconnect with the new port.

Usage:

  • Bash
  • With API
  • GST API
# Use default MQTT port
gst-launch-1.0 ... ! dctfcapture mode=2 mqtt-port=1883 ...

# Use custom port
gst-launch-1.0 ... ! dctfcapture mode=2 mqtt-port=8883 ...
// Use default MQTT port
api_dctfcapture_set_mqtt_port(<element_object>, 1883);

// Use custom port
api_dctfcapture_set_mqtt_port(<element_object>, 8883);
// Use default MQTT port
g_object_set(<element_object>, "mqtt-port", 1883, NULL);

// Use custom port
g_object_set(<element_object>, "mqtt-port", 8883, NULL);

time-skip​

Specifies the minimum time between captures in milliseconds for AUTO mode. This prevents capturing too frequently when object detection messages arrive rapidly.

  • Type: Integer (Unsigned)
  • Default: 500
  • Range: 0-60000 milliseconds
  • Access: Read/Write
note

Only effective in AUTO mode (mode=2). Use 0 for no throttling (per-frame detection).

Usage:

  • Bash
  • With API
  • GST API
# Capture at most once every 100ms (10 fps max)
gst-launch-1.0 ... ! dctfcapture mode=2 time-skip=100 ...

# No throttling - capture every frame
gst-launch-1.0 ... ! dctfcapture mode=2 time-skip=0 ...
// Capture at most once every 100ms
api_dctfcapture_set_time_skip(<element_object>, 100);

// No throttling
api_dctfcapture_set_time_skip(<element_object>, 0);
// Capture at most once every 100ms
g_object_set(<element_object>, "time-skip", 100, NULL);

// No throttling
g_object_set(<element_object>, "time-skip", 0, NULL);
