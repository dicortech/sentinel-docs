API Reference

This page provides a complete API reference for the PID Object Tracker library.

Core Classes - ObjectTrackerLib​

Main library interface for object tracking and PID control.

Namespace: DctotrackPID

Constructor​

ObjectTrackerLib(const FrameResolution& model_res,
                 const FrameResolution& display_res);

Creates a new object tracker instance with specified model and display resolutions.

Parameters:

  • model_res: Resolution used by the AI detection model
  • display_res: Resolution of the display/output frame

Configuration APIs​

Tracking Enable/Disable​

void ai_obj_trk_enable();
void ai_obj_trk_disable();
bool ai_obj_trk_is_enabled() const;

Enable or disable object tracking. When disabled, calculatePanTiltCommand() returns invalid commands.

Resolution Configuration​

void ai_obj_trk_set_model_resolution(int width, int height);
void ai_obj_trk_set_display_resolution(int width, int height);
void ai_obj_trk_set_resolutions(int model_width, int model_height,
                               int display_width, int display_height);

Configure the resolution settings. The tracker automatically converts coordinates between model and display space.

Parameters:

  • width, height: Resolution dimensions in pixels
  • model_width, model_height: Model resolution dimensions
  • display_width, display_height: Display resolution dimensions

Target Selection​

bool ai_obj_trk_set_target_id(int id);
int ai_obj_trk_get_target_id() const;
bool ai_obj_trk_set_by_coordinate(float x, float y);

Select which object to track. You can select by tracking ID or by clicking coordinates.

Parameters:

  • id: Tracking ID of the object to follow
  • x, y: Display coordinates (the closest object to these coordinates will be selected)

Returns: true if target was set successfully

Tracking Mode​

bool ai_obj_trk_set_mode(TrackingMode mode);
TrackingMode ai_obj_trk_get_mode() const;

Set the tracking mode: CENTROID (keep object at center) or ROI (keep object within ROI bounds).

Parameters:

  • mode: Either TrackingMode::CENTROID or TrackingMode::ROI

Returns: true if mode was set successfully

ROI Configuration​

bool ai_obj_trk_set_roi(float x, float y, float width, float height);
ROI ai_obj_trk_get_roi() const;

Configure the Region of Interest for ROI tracking mode.

Parameters:

  • x, y: Top-left corner coordinates (in display space)
  • width, height: ROI dimensions

Returns: true if ROI was set successfully

PID Tuning​

void ai_obj_trk_set_pid_gains(float pan_kp, float pan_ki, float pan_kd,
                              float tilt_kp, float tilt_ki, float tilt_kd);
void ai_obj_trk_reset_pid_controllers();
void ai_obj_trk_set_pid_limits(float min_output, float max_output);
void ai_obj_trk_set_filtering_params(float deadband_threshold,
                                     float smoothing_factor);

Fine-tune PID controller parameters for optimal tracking performance.

Parameters:

  • pan_kp, tilt_kp: Proportional gains (default: 0.10)
  • pan_ki, tilt_ki: Integral gains (default: 0.001)
  • pan_kd, tilt_kd: Derivative gains (default: 0.015)
  • min_output, max_output: Output limits (default: -60.0, 60.0)
  • deadband_threshold: Minimum error to generate command (default: 0.05)
  • smoothing_factor: Output smoothing factor 0-1 (default: 0.8)

Processing APIs​

Update Detections​

void ai_obj_trk_update_detections(const std::vector<DetectedObject>& objects);

Update the tracker with new detection results from your object detection pipeline.

Parameters:

  • objects: Vector of detected objects with tracking IDs

Calculate Camera Movement​

PanTiltCommand calculatePanTiltCommand();

Calculate the pan/tilt command based on current tracking state.

Returns: PanTiltCommand structure with pan_delta, tilt_delta, and valid flag

Query Tracking State​

std::vector<int> ai_obj_trk_get_available_ids() const;
bool ai_obj_trk_get_current_target(DetectedObject& target) const;

Query available object IDs and get the currently tracked object.

Parameters:

  • target: Output parameter to receive current target object

Returns:

  • ai_obj_trk_get_available_ids(): List of all available tracking IDs
  • ai_obj_trk_get_current_target(): true if a target is currently being tracked

Utility APIs​

void initializeWithConfig(const std::string& config_params = "");
static void setLogLevel(LogLevel level);
void printStatus() const;
std::string ai_obj_trk_get_mode_string() const;

Parameters:

  • config_params: Optional configuration string (reserved for future use)
  • level: Logging level (LOG_DEBUG, INFO, WARNING, ERROR, NONE)

Core Classes - MQTTObjectTracker​

MQTT integration wrapper for receiving object detections automatically.

Constructor​

MQTTObjectTracker(const FrameResolution& model_res,
                  const FrameResolution& display_res);

Creates a new MQTT-enabled object tracker instance.

Key Methods​

Access Underlying Tracker​

ObjectTrackerLib* getTracker();

Get access to the underlying ObjectTrackerLib instance for configuration.

Returns: Pointer to the tracker instance

MQTT Configuration​

bool initializeMQTT(const MQTTConfig& config);
bool startMQTT();
void stopMQTT();

Initialize and control MQTT communication.

Parameters:

  • config: MQTT configuration structure with broker details

Returns: true if operation succeeded

MQTT Status​

bool isMQTTEnabled() const;
bool isMQTTConnected() const;
void printMQTTStatus() const;

Query MQTT connection status.

Dynamic Subscription Management​

bool subscribe(const std::string& topic, int qos = 1);
bool unsubscribe(const std::string& topic);
void setDetectionTopic(const std::string& topic);

Dynamically manage MQTT subscriptions at runtime.

Parameters:

  • topic: MQTT topic to subscribe/unsubscribe
  • qos: Quality of Service level (0, 1, or 2)

Returns: true if operation succeeded

Manual Updates​

void manualUpdateDetections(const std::vector<DetectedObject>& objects);

Manually update detections (alternative to MQTT mode).

Mode Control​

void enableMQTTMode();
void disableMQTTMode();

Enable or disable MQTT communication mode.

Data Structures​

DetectedObject​

Represents a detected and tracked object.

struct DetectedObject {
    int id;              // Object tracking ID
    float x, y;          // Center coordinates
    float width, height; // Bounding box dimensions
    float confidence;    // Detection confidence (0.0 to 1.0)
};

Fields:

  • id: Unique tracking ID (persistent across frames)
  • x, y: Object center coordinates in model resolution
  • width, height: Bounding box dimensions
  • confidence: Detection confidence score (0.0 = 0%, 1.0 = 100%)

FrameResolution​

Defines frame dimensions.

struct FrameResolution {
    int width;   // Frame width in pixels
    int height;  // Frame height in pixels
};

PanTiltCommand​

Output structure containing camera movement commands.

struct PanTiltCommand {
    float pan_delta;   // Horizontal movement (-1.0 to 1.0)
    float tilt_delta;  // Vertical movement (-1.0 to 1.0)
    bool valid;        // Whether command is valid
};

Fields:

  • pan_delta: Horizontal camera movement (-1.0 = left, 1.0 = right, 0.0 = no movement)
  • tilt_delta: Vertical camera movement (-1.0 = down, 1.0 = up, 0.0 = no movement)
  • valid: Set to true if command contains valid data (tracking enabled and target found)

ROI (Region of Interest)​

Defines a rectangular region for ROI tracking mode.

struct ROI {
    float x, y;           // Top-left corner coordinates
    float width, height;  // ROI dimensions

    std::pair<float, float> getCenter() const;
};

Methods:

  • getCenter(): Returns the center point coordinates of the ROI

MQTTConfig​

MQTT connection configuration.

struct MQTTConfig {
    std::string broker_host;      // MQTT broker hostname/IP
    int broker_port;              // MQTT broker port (default: 1883)
    std::string client_id;        // MQTT client identifier
    std::string detection_topic;  // Topic for object detections
    std::string username;         // MQTT username (optional)
    std::string password;         // MQTT password (optional)
    int keepalive;               // Keep-alive interval (default: 60)
    bool clean_session;          // Clean session flag (default: true)
    int qos;                     // Quality of Service (default: 1)
};

Example:

MQTTConfig config;
config.broker_host = "192.168.1.100";
config.broker_port = 1883;
config.client_id = "camera_tracker";
config.detection_topic = "ai/detections/camera1";

TrackerConfig​

Advanced tracker configuration parameters.

struct TrackerConfig {
    // PID output limits
    float pid_output_min;      // Default: -60.0
    float pid_output_max;      // Default: 60.0

    // Command filtering
    float deadband_threshold;  // Default: 0.05
    float smoothing_factor;    // Default: 0.8

    // Time delta limits
    float min_time_delta;      // Default: 0.001 (1ms)
    float max_time_delta;      // Default: 1.0 (1s)
    float default_time_delta;  // Default: 0.033 (~30 FPS)

    // Resolution limits
    int max_resolution_dimension;  // Default: 10000

    // ROI defaults
    float default_roi_width_percent;   // Default: 0.2 (20%)
    float default_roi_height_percent;  // Default: 0.28 (28%)

    // PID gain limits
    float max_proportional_gain;  // Default: 10.0
    float max_integral_gain;      // Default: 1.0
};

Enumerations​

TrackingMode​

enum class TrackingMode {
    CENTROID,  // Keep object at frame center
    ROI        // Keep object within defined ROI
};

Values:

  • CENTROID: Camera adjusts to keep the tracked object at the center of the frame
  • ROI: Camera only moves when the object approaches or exits the ROI boundaries

LogLevel​

enum class LogLevel {
    LOG_DEBUG = 0,
    INFO = 1,
    WARNING = 2,
    ERROR = 3,
    NONE = 4
};

Example:

ObjectTrackerLib::setLogLevel(LogLevel::LOG_DEBUG);

MQTT Message Format​

The library expects object detection messages in JSON format:

{
  "detections": [
    {
      "id": 1,
      "x": 320,
      "y": 240,
      "width": 80,
      "height": 120,
      "confidence": 0.95,
      "class": "person"
    }
  ]
}

Field Descriptions:

  • id: Tracking ID (persistent across frames)
  • x, y: Center coordinates in model resolution
  • width, height: Bounding box dimensions
  • confidence: Detection confidence score (0.0 to 1.0)
  • class: Object class name (optional, not used by tracker)

Using in Your Project​

With pkg-config​

g++ myapp.cpp $(pkg-config --cflags --libs pid_otrack) -o myapp

Manual Linking​

g++ myapp.cpp \
    -I/path/to/pid_otrack/inc \
    -L/path/to/pid_otrack/build \
    -lpid_otrack \
    -lmosquitto \
    -lcjson \
    -o myapp

CMake Integration​

find_library(PID_OTRACK_LIB pid_otrack)
target_link_libraries(myapp ${PID_OTRACK_LIB})
