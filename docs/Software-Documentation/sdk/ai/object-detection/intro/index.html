Plugin Overview

This page describes the Object Detection Plugin (dctobd), a GStreamer plugin that enables AI-powered object detection on Sentinel SoM using the Synaptics SyNAP framework backend.

Overview​

The Object Detection Plugin provides two GStreamer elements that work together to perform real-time object detection on video streams:

1. dctobd (Object Detection Transform Element)

The dctobd element performs object detection inference on incoming video frames. It accepts RGB video input, runs the detection model, and outputs the video frames with detection metadata attached.

2. dctobdsink (Object Detection Sink Element)

The dctobdsink element writes detection results to a file. It can output results in JSON format or attach overlay metadata for rendering.

Key Features​

  1. Model Management - Dynamic model selection and directory scanning
  2. Detection Control - Enable/disable detection at runtime
  3. Class Filtering - Select specific object classes to detect
  4. Threshold Control - Adjust confidence threshold dynamically
  5. Inference Statistics - Optional performance monitoring

Architecture​

The plugin follows a three-layer architecture for modularity and maintainability:

1. API Layer (inc/api/, src/api/)​

Provides a clean, high-level C API for applications with functions like:

  • api_dctobd_set_model() - Set model file path
  • api_dctobd_set_confidence_threshold() - Configure detection threshold
  • api_dctobd_set_enabled_classes() - Filter specific object classes

2. GStreamer Layer (inc/gst/, src/gst/)​

Handles GStreamer plugin implementation:

  • Pipeline integration and caps negotiation
  • Property management
  • Buffer processing and metadata attachment

3. Machine Layer (inc/mach/, src/mach/)​

Platform-specific inference implementation:

  • SyNAP (mach_synap.cpp) - Hardware-accelerated neural network operations

Quick Start​

To run object detection on a video stream, use the following command:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector frameinterval=3 ! \
    dctobdsink location=results.txt
note

Ensure that the video format is set to RGB and the resolution matches your model's input size before passing it to the dctobd element.

Supported Input Formats​

  • Video Format: RGB only (use videoconvert for other formats)
  • Resolution: Must match the model's expected input dimensions
  • Color Space: Standard RGB color space

Requirements​

To use the Object Detection Plugin, you will need the following dependencies installed on Sentinel SoM:

For SyNAP Backend (MACH_SYNAP)​

  • GStreamer 1.0 development libraries
  • Synaptics SyNAP framework libraries (synap_app, synap_base, synap_utils, synap_img, synapnb, synap_preprocess, synap_postprocess)
  • Pre-trained object detection model (.synap format)
