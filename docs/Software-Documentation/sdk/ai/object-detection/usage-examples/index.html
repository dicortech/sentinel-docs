Examples

This page demonstrates common usage patterns for the Object Detection plugin on Sentinel SoM.

Pipeline Setup Guidelines​

Required Pipeline Elements​

For proper operation, your pipeline should include:

  1. videoconvert - Converts any video format (YUV, NV12, BGRA, etc.) to RGB
  2. videoscale - Resizes video to match model's expected resolution
  3. Caps filter - Explicitly specify video/x-raw,format=RGB,width=W,height=H

Example pipeline structure:

[source] ! videoconvert ! videoscale ! \
  video/x-raw,format=RGB,width=640,height=384 ! \
  dctobd model=/path/to/model.synap mode=detector ! \
  [sink]

Basic Detection​

To run object detection with default settings, execute the following pipeline:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector frameinterval=3 ! \
    dctobdsink location=results.txt

This pipeline captures video from /dev/video8, converts it to RGB format, and runs object detection. Results are written to results.txt in JSON format.

Class-Specific Detection​

To detect only specific object classes, use the enabled-classes property:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector enabled-classes="person,car,bicycle" frameinterval=3 ! \
    dctobdsink location=results.txt

This configuration will only detect persons, cars, and bicycles, ignoring all other object classes.

Adjusting Detection Threshold​

To use a higher confidence threshold for more accurate detections, set the threshold property:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector threshold=0.75 frameinterval=3 ! \
    dctobdsink location=results.txt

A threshold of 0.75 means only detections with 75% or higher confidence will be reported.

Application Examples​

The following examples demonstrate how to use the Object Detection plugin in C applications.

Configuring Detection at Runtime​

GstElement *dctobd = gst_element_factory_make("dctobd", "detector");

// Set the model path
g_object_set(dctobd, "model", "/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap", NULL);

// Configure detection parameters
g_object_set(dctobd, "mode", "detector", NULL);
g_object_set(dctobd, "enabled-classes", "person,car", NULL);
g_object_set(dctobd, "threshold", 0.7f, NULL);

Querying Available Classes​

// After the model is loaded, query available classes
gchar *available_classes = NULL;
g_object_get(dctobd, "available-classes", &available_classes, NULL);
g_print("Available classes: %s\n", available_classes);
g_free(available_classes);

Common Use Cases​

Person Detection​

This configuration optimizes for detecting people with high confidence:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector enabled-classes="person" threshold=0.7 frameinterval=3 ! \
    dctobdsink location=person_detection.txt

Vehicle Detection​

This configuration detects multiple vehicle types:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector enabled-classes="car,truck,bus,motorcycle" threshold=0.6 frameinterval=5 ! \
    dctobdsink location=vehicle_detection.txt
note

Adjust the frameinterval parameter based on your performance requirements. Higher values reduce CPU usage but may miss rapid changes in the scene.

Video File and RTSP Sources​

Video File Input​

gst-launch-1.0 filesrc location=video.mp4 ! decodebin ! \
    videoconvert ! videoscale ! \
    video/x-raw,format=RGB,width=640,height=384 ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector frameinterval=3 ! \
    fakesink

RTSP Stream Input​

gst-launch-1.0 rtspsrc location=rtsp://camera_ip/stream ! \
    rtph264depay ! h264parse ! decodebin ! \
    videoconvert ! videoscale ! \
    video/x-raw,format=RGB,width=640,height=384 ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector frameinterval=3 ! \
    fakesink

Debugging and Monitoring​

Enable Debug Logging​

To see detailed plugin logs, set the GST_DEBUG environment variable:

# Show only DCTOBD plugin debug messages (recommended)
GST_DEBUG=dctobd:4,dctobdsink:4 gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector frameinterval=3 ! \
    dctobdsink location=/tmp/results.txt

# Show all GStreamer debug messages (very verbose)
GST_DEBUG=*:3 gst-launch-1.0 ...

Debug levels:

  • 0: No output
  • 1: ERROR
  • 2: WARNING
  • 3: INFO
  • 4: DEBUG
  • 5: LOG (verbose)

Enable Inference Statistics​

Monitor inference performance:

gst-launch-1.0 v4l2src device=/dev/video8 ! videoconvert ! videoscale ! \
    video/x-raw,width=640,height=384,format=RGB ! \
    dctobd model=/usr/share/synap/models/object_detection/coco/model/yolov8s-640x384/model.synap \
    mode=detector inferstatistics=true frameinterval=3 ! \
    dctobdsink location=results.txt

This will log average inference time when the pipeline stops.

Dynamic Property Changes​

You can change detection parameters at runtime using GStreamer's property system:

GstElement *dctobd = gst_element_factory_make("dctobd", "detector");

// Start with person detection
g_object_set(dctobd, "enabled-classes", "person", NULL);
g_object_set(dctobd, "threshold", 0.7f, NULL);

// Run pipeline...
gst_element_set_state(pipeline, GST_STATE_PLAYING);

// Later, switch to vehicle detection
g_object_set(dctobd, "enabled-classes", "car,truck,bus,motorcycle", NULL);
g_object_set(dctobd, "threshold", 0.6f, NULL);

// Temporarily disable detection
g_object_set(dctobd, "detection-enabled", FALSE, NULL);

// Re-enable with new settings
g_object_set(dctobd, "detection-enabled", TRUE, NULL);
g_object_set(dctobd, "threshold", 0.8f, NULL);

Troubleshooting Common Issues​

Issue: "Unsupported video format" Error​

Cause: The plugin only accepts RGB format input.

Solution: Add videoconvert before the dctobd element:

... ! videoconvert ! video/x-raw,format=RGB ! dctobd...

Issue: "Resolution mismatch" Error​

Cause: Video resolution doesn't match model's expected input.

Solution: Add videoscale and specify correct resolution:

... ! videoscale ! video/x-raw,format=RGB,width=640,height=384 ! dctobd...

Issue: No Detections Appearing​

Possible Solutions:

  1. Lower the threshold: threshold=0.3
  2. Check detection is enabled: detection-enabled=true
  3. Verify enabled classes match scene objects
  4. Check frame interval isn't too high
  5. Enable debug logging to see format/resolution info

Issue: Class Filtering Not Working​

Possible Solutions:

  1. Ensure label file exists (set via label property)
  2. Check class name spelling and case sensitivity
  3. Query available classes first:
gchar *available = NULL;
g_object_get(dctobd, "available-classes", &available, NULL);
g_print("Available: %s\n", available);
g_free(available);
