Info Messages

The overlay plugin provides an info message feature that allows you to display custom text messages at any position on the video frame. Unlike detection overlays that show bounding boxes based on object detection results, info messages are arbitrary text displays useful for system status, alerts, notifications, and other informational content.

Overview​

Info messages provide a flexible way to overlay custom text content on video frames with full control over:

  • Position: Place messages anywhere on the frame
  • Styling: Customize fonts, colors, bold/italic formatting
  • Bounding Box: Optional border around text
  • Background: Semi-transparent background for better visibility
  • Persistence: Auto-expiring or permanent messages
  • Dynamic Updates: Add, update, or remove messages via MQTT

Architecture​

The info message system is implemented as two coordinated layers.

The communication layer (comm_info_message) is responsible for message lifecycle management. It parses incoming JSON commands, maintains a thread-safe list of active messages, enforces message limits, and handles automatic expiration based on persistence time. Messages are uniquely identified by an ID, allowing updates to replace existing entries without restarting the plugin.

The machine layer (mach_info_message) handles rendering. It draws the text onto video frames using OpenCV, applying font styling, optional bounding boxes, and background transparency. Rendering occurs on every frame for all active messages.

Message Format​

Info messages are controlled via JSON commands sent through MQTT. The expected format:

{
  "command": "add_info_message",
  "id": "unique_message_id",
  "message": "Text to display",
  "pos_x": 100,
  "pos_y": 50,
  "font_size": 14,
  "font_color": "#FFFFFF",
  "font_bold": false,
  "font_italic": false,
  "bbox": false,
  "bbox_color": "#00FF00",
  "bbox_thickness": 2,
  "bbox_bgnd_color": "#000000",
  "bbox_bgnd_alpha": 0.7,
  "persist": 5
}

Required Parameters​

ParameterTypeDescription
commandstringMust be "add_info_message"
idstringUnique message identifier (max 64 chars)
messagestringText to display (max 256 chars)
pos_xintX position in pixels
pos_yintY position in pixels

Optional Parameters​

ParameterTypeDefaultDescription
font_sizeint14Font size in points
font_colorstring"#FFFFFF"Text color (hex format)
font_boldboolfalseEnable bold text
font_italicboolfalseEnable italic text
font_underlineboolfalseUnderline text (not implemented in OpenCV)
bboxboolfalseEnable bounding box around text
bbox_colorstring"#00FF00"Box border color (hex)
bbox_thicknessint2Box border thickness in pixels
bbox_bgnd_colorstringnoneBackground color (hex)
bbox_bgnd_alphafloat0.7Background transparency (0.0-1.0)
persistint0Seconds to display (0 = forever)
Color Format

Colors are specified in hex format with or without the # prefix (e.g., "#FF0000" or "FF0000" for red).

Integration with Plugin​

MQTT Topic Configuration​

The info message feature uses the same MQTT connection as the detection overlay. Configure the MQTT topic via the plugin property:

# GStreamer pipeline example
gst-launch-1.0 \
  videotestsrc ! \
  video/x-raw,format=BGR ! \
  dctoverlay \
    mqtt-host=localhost \
    mqtt-port=1883 \
    mqtt-topic=overlay/commands ! \
  videoconvert ! \
  autovideosink

C API Usage​

The info message feature can also be used programmatically:

#include "comm_info_message.h"

// Initialize context
InfoMessageContext *ctx = info_message_init();

// Create message
InfoMessage msg = {0};
strncpy(msg.id, "alert_001", INFO_MESSAGE_MAX_ID);
strncpy(msg.message, "Alert: Motion Detected", INFO_MESSAGE_MAX_TEXT);
msg.pos_x = 100;
msg.pos_y = 50;
msg.font.font_size = 16;
msg.font.font_color_r = 255;
msg.font.font_color_g = 0;
msg.font.font_color_b = 0;
msg.persist_seconds = 5;

// Add message
info_message_add(ctx, &msg);

// Get active messages
InfoMessage *messages = NULL;
int count = 0;
if (info_message_get_active(ctx, &messages, &count)) {
    // Render messages on frame
    for (int i = 0; i < count; i++) {
        // Process message
    }
    free(messages);
}

// Cleanup
info_message_cleanup(ctx);

Usage Examples​

Basic Message​

Display a simple white text message that expires after 5 seconds:

  • mosquitto_pub
  • Python
mosquitto_pub -h localhost -t overlay/commands -m '{
  "command": "add_info_message",
  "id": "alert_001",
  "message": "Detection Alert: Person detected",
  "pos_x": 50,
  "pos_y": 50,
  "font_size": 16,
  "font_color": "#FF0000",
  "persist": 5
}'
import paho.mqtt.client as mqtt
import json

client = mqtt.Client()
client.connect("localhost", 1883)

message = {
    "command": "add_info_message",
    "id": "alert_001",
    "message": "Detection Alert: Person detected",
    "pos_x": 50,
    "pos_y": 50,
    "font_size": 16,
    "font_color": "#FF0000",
    "persist": 5
}

client.publish("overlay/commands", json.dumps(message))
client.disconnect()

  "bbox": true,
  "bbox_color": "#FF0000",

  "persist": 10

Message with Background​

Add a semi-transparent background for better visibility:

{
  "command": "add_info_message",
  "id": "status_bg",
  "message": "System Status: ACTIVE",
  "pos_x": 200,
  "pos_y": 50,

Persistent Message​

Create a message that never expires (persist = 0):

{
  "command": "add_info_message",
  "id": "permanent_status",
  "message": "Recording in Progress",
  "pos_x": 20,
  "pos_y": 20,
  "font_size": 12,
  "font_color": "#FF0000",
  "font_bold": true,
  "persist": 0
}

Updating a Message​

To update an existing message, send a new message with the same ID. The old message will be replaced:

{
  "command": "add_info_message",
  "id": "alert_001",
  "message": "Detection Alert: Person CLEARED",
  "pos_x": 50,
  "pos_y": 50,
  "font_size": 16,
  "font_color": "#00FF00",
  "persist": 5
}

Styled Text​

Combine multiple styling options:

{
  "command": "add_info_message",
  "id": "styled_message",
  "message": "CRITICAL ALERT",
  "pos_x": 300,
  "pos_y": 150,
  "font_size": 20,
  "font_color": "#FFFFFF",
  "font_bold": true,
  "font_italic": true,
  "bbox": true,

  "bbox_thickness": 3,
  "bbox_bgnd_color": "#800000",
  "bbox_bgnd_alpha": 0.8,
  "persist": 0
}

Message Management​

Adding Messages​

Send a JSON message with the add_info_message command via MQTT to the configured topic (default: overlay/commands).

Updating Messages​

Send a new message with the same id. The existing message will be replaced with the new content and styling. The persistence timer resets.

Removing Messages​

Messages are automatically removed when they expire (based on the persist parameter). For messages with persist: 0, they remain until:

  1. Replaced with a new message using the same ID
  2. The plugin is restarted
  3. All messages are cleared programmatically

Message Limits​

  • Maximum concurrent messages: 10
  • Maximum message text: 256 characters
  • Maximum ID length: 64 characters

When the maximum number of messages is reached, new messages will fail to be added unless an existing message expires or is replaced.

Behavior Details​

Persistence​

  • persist: N (N > 0): Message disappears after N seconds
  • persist: 0: Message stays forever until replaced or plugin restarts
  • Timer starts when the message is added
  • Updating a message (same ID) resets the timer

Expiration Handling​

Expired messages are automatically removed when info_message_get_active() is called. The plugin checks message expiration times on each frame rendering.

Rendering Order​

Messages are rendered in the order they are stored in the context. Messages added first appear "behind" messages added later if they overlap.
