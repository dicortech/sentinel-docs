Property Details​

MQTT Configuration Properties​

mqtt-host​

Specifies the MQTT broker hostname or IP address.

  • Type: String
  • Default: "localhost"
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay mqtt-host=192.168.1.100 ...
api_dctoverlay_set_mqtt_host(<element_object>, "192.168.1.100");
g_object_set(<element_object>, "mqtt-host", "192.168.1.100", NULL);

mqtt-port​

Specifies the MQTT broker port number.

  • Type: Integer
  • Default: 1883
  • Range: 1-65535
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay mqtt-port=1883 ...
api_dctoverlay_set_mqtt_port(<element_object>, 1883);
g_object_set(<element_object>, "mqtt-port", 1883, NULL);

mqtt-client-id​

Specifies the MQTT client identifier.

  • Type: String
  • Default: Auto-generated
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay mqtt-client-id=overlay_client_1 ...
api_dctoverlay_set_mqtt_client_id(<element_object>, "overlay_client_1");
g_object_set(<element_object>, "mqtt-client-id", "overlay_client_1", NULL);

mqtt-topic​

Specifies the MQTT topic to subscribe for detection messages.

  • Type: String
  • Default: "detections"
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay mqtt-topic=detections ...
api_dctoverlay_set_mqtt_topic(<element_object>, "detections");
g_object_set(<element_object>, "mqtt-topic", "detections", NULL);

mqtt-qos​

Specifies the MQTT Quality of Service level.

  • Type: Integer
  • Default: 1
  • Range: 0-2
  • Access: Read/Write
  • Values:
    • 0: At most once delivery
    • 1: At least once delivery
    • 2: Exactly once delivery

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay mqtt-qos=1 ...
api_dctoverlay_set_mqtt_qos(<element_object>, 1);
g_object_set(<element_object>, "mqtt-qos", 1, NULL);

Bounding Box Styling Properties​

bbox-colour​

Specifies the bounding box color as a hex string. Automatically parses to RGB components and optional alpha.

  • Type: String
  • Default: NULL (must use bbox-colour-r/g/b or set via hex)
  • Format: "#RGB", "#RGBA", "#RRGGBB", or "#RRGGBBAA"
  • Access: Read/Write
Alpha in Hex

You can specify transparency directly in the hex string using the #RRGGBBAA format. For example, #00FF0080 creates a 50% transparent green (0x80 = 128 = 50% of 255).

Usage:

  • Bash
  • GST API
# Green boxes (fully opaque)
gst-launch-1.0 ... ! dctoverlay bbox-colour="#00FF00" ...

# Red boxes (short format)
gst-launch-1.0 ... ! dctoverlay bbox-colour="#F00" ...

# Semi-transparent blue boxes (80% opacity)
gst-launch-1.0 ... ! dctoverlay bbox-colour="#0000FFCC" ...

# Short format with alpha (50% red)
gst-launch-1.0 ... ! dctoverlay bbox-colour="#F008" ...
// Opaque green
g_object_set(<element_object>, "bbox-colour", "#00FF00", NULL);

// Semi-transparent green (70% opacity)
g_object_set(<element_object>, "bbox-colour", "#00FF00B3", NULL);

bbox-colour-r, bbox-colour-g, bbox-colour-b​

Specifies the bounding box color in RGB components.

  • Type: Integer (each component)
  • Default: R=-1, G=-1, B=-1 (not set, must use bbox-colour hex string)
  • Range: -1 (not set) or 0-255
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
# Green boxes
gst-launch-1.0 ... ! dctoverlay bbox-colour-r=0 bbox-colour-g=255 bbox-colour-b=0 ...

# Yellow boxes
gst-launch-1.0 ... ! dctoverlay bbox-colour-r=255 bbox-colour-g=255 bbox-colour-b=0 ...
// Green boxes
api_dctoverlay_set_box_color(<element_object>, 0, 255, 0);

// Yellow boxes
api_dctoverlay_set_box_color(<element_object>, 255, 255, 0);
// Green boxes
g_object_set(<element_object>,
            "bbox-colour-r", 0,
            "bbox-colour-g", 255,
            "bbox-colour-b", 0,
            NULL);

bbox-thickness​

Specifies the bounding box border thickness.

  • Type: Integer
  • Default: 2
  • Range: 1-50 pixels
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay bbox-thickness=2 ...
api_dctoverlay_set_box_thickness(<element_object>, 2);
g_object_set(<element_object>, "bbox-thickness", 2, NULL);

Label Configuration Properties​

draw-label-background​

Enables or disables the label background.

  • Type: Boolean
  • Default: true
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay draw-label-background=true ...
api_dctoverlay_set_label_background(<element_object>, true);
g_object_set(<element_object>, "draw-label-background", TRUE, NULL);

label-bg-colour​

Specifies the label background color as a hex string with optional alpha. When alpha is specified in the hex string, it overrides the label-bg-alpha property.

  • Type: String
  • Default: NULL (uses label-bg-colour-r/g/b values)
  • Format: "#RGB", "#RGBA", "#RRGGBB", or "#RRGGBBAA"
  • Access: Read/Write
Combined Color and Alpha

Instead of setting label-bg-colour and label-bg-alpha separately, you can use #RRGGBBAA format to set both at once. For example, #000000B3 creates a 70% opaque black background.

Usage:

  • Bash
  • GST API
# Black background (use label-bg-alpha for transparency)
gst-launch-1.0 ... ! dctoverlay label-bg-colour="#000000" label-bg-alpha=0.7 ...

# Black background with 70% opacity (alpha in hex)
gst-launch-1.0 ... ! dctoverlay label-bg-colour="#000000B3" ...

# Semi-transparent dark blue background (50% opacity)
gst-launch-1.0 ... ! dctoverlay label-bg-colour="#00008080" ...
// Black with 70% opacity via hex alpha
g_object_set(<element_object>, "label-bg-colour", "#000000B3", NULL);

// Equivalent using separate alpha property
g_object_set(<element_object>,
             "label-bg-colour", "#000000",
             "label-bg-alpha", 0.7,
             NULL);

label-bg-colour-r, label-bg-colour-g, label-bg-colour-b​

Specifies the label background color in RGB components.

  • Type: Integer (each component)
  • Default: R=0, G=0, B=0 (Black)
  • Range: 0-255
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
# Black background
gst-launch-1.0 ... ! dctoverlay label-bg-colour-r=0 label-bg-colour-g=0 label-bg-colour-b=0 ...
// Black background
api_dctoverlay_set_label_bg_color(<element_object>, 0, 0, 0);
g_object_set(<element_object>,
            "label-bg-colour-r", 0,
            "label-bg-colour-g", 0,
            "label-bg-colour-b", 0,
            NULL);

label-bg-alpha​

Specifies the label background transparency.

  • Type: Double
  • Default: 0.7
  • Range: 0.0 (transparent) to 1.0 (opaque)
  • Access: Read/Write
note

This property is overridden when alpha is specified in the label-bg-colour hex string (e.g., #000000B3).

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay label-bg-alpha=0.7 ...
api_dctoverlay_set_label_bg_alpha(<element_object>, 0.7);
g_object_set(<element_object>, "label-bg-alpha", 0.7, NULL);

label-position​

Specifies the label position relative to the bounding box.The detection label has boundary detection with a 30-pixel buffer zone that checks if the bounding box is near any screen edge. When a detection approaches the edges, the label automatically repositions itself: moving below the box when near the top edge, adjusting horizontally for left/right edges, or moving inside the box when there's no room outside. Labels now remain fully visible at all times preventing text cutoff regardless of where the tracked object moves on screen.

  • Type: Integer
  • Default: 0 (Top-Left)
  • Access: Read/Write
  • Values:
    • 0: Top-Left
    • 1: Top-Right
    • 2: Bottom-Left
    • 3: Bottom-Right

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctoverlay label-position=0 ...
api_dctoverlay_set_label_position(<element_object>, 0);  // Top-Left
g_object_set(<element_object>, "label-position", 0, NULL);

Region of Interest Properties​

enable-roi​

Enables or disables ROI rectangle drawing.

  • Type: Boolean
  • Default: false
  • Access: Read/Write

Usage:

  • Bash
  • GST API
gst-launch-1.0 ... ! dctoverlay enable-roi=true ...
g_object_set(<element_object>, "enable-roi", TRUE, NULL);

roi-display-mode​

Specifies when to display the ROI rectangle.

  • Type: Enum
  • Default: always
  • Values:
    • always: ROI is always visible
    • on-detection: ROI is only visible when detections occur
  • Access: Read/Write

Usage:

  • Bash
  • GST API
gst-launch-1.0 ... ! dctoverlay roi-display-mode=on-detection ...
g_object_set(<element_object>, "roi-display-mode", 1, NULL);  // 0=always, 1=on-detection

roi-x, roi-y, roi-width, roi-height​

Specifies the ROI rectangle position and dimensions.

  • Type: Integer (each property)
  • Default: x=0, y=0, width=640, height=480
  • Access: Read/Write

Usage:

  • Bash
  • GST API
gst-launch-1.0 ... ! dctoverlay roi-x=100 roi-y=100 roi-width=400 roi-height=300 ...
g_object_set(<element_object>,
            "roi-x", 100,
            "roi-y", 100,
            "roi-width", 400,
            "roi-height", 300,
            NULL);

roi-colour​

Specifies the ROI border color as a hex string with optional alpha.

  • Type: String
  • Default: NULL (defaults to yellow)
  • Format: "#RGB", "#RGBA", "#RRGGBB", or "#RRGGBBAA"
  • Access: Read/Write

Usage:

# Yellow ROI border
gst-launch-1.0 ... ! dctoverlay roi-colour="#FFFF00" ...

# Semi-transparent yellow ROI (80% opacity)
gst-launch-1.0 ... ! dctoverlay roi-colour="#FFFF00CC" ...

roi-colour-r, roi-colour-g, roi-colour-b​

Specifies the ROI border color in RGB components.

  • Type: Integer (each component)
  • Default: R=255, G=255, B=0 (Yellow)

  • Access: Read/Write

roi-thickness​

Specifies the ROI border thickness.

  • Type: Integer
  • Default: 2
  • Range: 1-50 pixels
  • Access: Read/Write

centroid-radius​

Specifies the radius of the ROI centroid marker dot.
