Voice Command Application

The Voice Command Application (Mantis Voice Control) is a standalone C++ application that provides offline voice command recognition with wake word detection. It uses the Vosk speech recognition library for local, privacy-preserving speech-to-text conversion and implements a trigger-based command system for controlling devices and applications.

Features​

  • Offline Speech Recognition: No internet connection required, all processing happens locally using Vosk
  • Wake Word Detection: Trigger phrase ("Mantis") activation for command listening
  • Fuzzy Matching: Tolerant command matching using Levenshtein distance algorithm
  • Multiple Communication Backends: Send commands via TCP, MQTT, or console output
  • Configurable Commands: JSON-based command definitions with multiple phrase variants
  • Grammar Support: Custom keyword grammar for improved recognition accuracy
  • Hot Reload: Reload command definitions without restarting (SIGUSR2)
  • Low Latency: Real-time audio processing with ALSA integration
  • Resource Efficient: Suitable for embedded ARM64 systems

Architecture​

The application follows a multi-threaded architecture with two main components:

1. ALSA Capture Thread​

  • Captures audio from microphone at 16kHz stereo
  • Converts stereo to mono
  • Buffers audio in thread-safe queue
  • Handles PCM underruns and errors

2. Vosk Processing Thread​

  • Consumes audio from queue
  • Performs speech recognition using Vosk model
  • Detects trigger phrase ("Mantis")
  • Matches commands using fuzzy logic
  • Sends commands via TCP socket

Communication Flow​

┌─────────────┐
│ Microphone  │
└──────┬──────┘
       │ ALSA Capture (16kHz Stereo)
       ▼
┌─────────────────┐
│  Audio Queue    │ (Thread-safe)
└──────┬──────────┘
       │ Mono PCM
       ▼
┌─────────────────┐
│  Vosk Engine    │
└──────┬──────────┘
       │ JSON Results
       ▼
┌─────────────────┐
│ Trigger Monitor │ (5-second window)
└──────┬──────────┘
       │ Wake word detected
       ▼
┌─────────────────┐
│ Command Matcher │ (Fuzzy matching)
└──────┬──────────┘
       │ Matched command
       ▼
┌─────────────────┐
│  TCP Client     │ → Send to device (localhost:6975)
└─────────────────┘

Build Instructions​

Prerequisites​

Build Dependencies:

  • C++17 compatible compiler (g++ 7.0+)
  • Standard C++ libraries (stdc++)
  • ALSA development libraries (libasound2-dev)
  • Vosk library (libvosk.so version 0.3.45)
  • Vosk API headers (vosk_api.h)
  • pthread support

Build Instructions​

Note: Both the Vosk library and Vosk models are automatically provided and pre-installed via the BitBake recipe:

  • Vosk library: Included as a dependency in the sentinel-sdk recipe
  • Vosk models: Pre-installed at /home/root/models/stt/vosk/
  • No manual downloads are required when building via Yocto

For Native Development:

If building outside of Yocto, you will need to have the Vosk library installed on your system.

cd apps/voice_commands/

# Build (requires Vosk library to be available in system paths)
make

For Yocto Cross-Compilation:

# The application is built as part of sentinel-sdk recipe
# Vosk library is automatically provided as a dependency
bitbake sentinel-sdk

# The binary will be installed to:
# /usr/share/sentinel-sdk/voice_command/voice_command

Usage​

Command-Line Options​

voice_command [OPTIONS]

Options:
  -d, --device <dev>          ALSA device (default: default)
  -v, --vosk-model <path>     Vosk model path (default: /home/root/models/stt/vosk/vosk-model-small-en-us-0.15)
  -k, --keywords-file <path>  Keywords file (default: keywords.txt)
  -c, --commands-file <path>  Commands file (default: commands.json)
  -h, --command-host <ip>     Command server host (default: 127.0.0.1)
  -p, --command-port <port>   Command server port (default: 6975)

Basic Usage​

./voice_command

# Or with custom options
./voice_command \
    --vosk-model /home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    --device plughw:1,0 \
    --command-host 127.0.0.1 \
    --command-port 6975

On Target Device (Yocto)​

./voice_command \
    --vosk-model /home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    --device default \
    --command-host 127.0.0.1 \
    --command-port 6975

# Or use the larger model for better accuracy
./voice_command \
    --vosk-model /home/root/models/stt/vosk/vosk-model-en-us-0.22-lgraph \
    --device default \
    --command-host 127.0.0.1 \
    --command-port 6975

Voice Command Workflow​

  1. Start Application

    ./voice_command
    # Output: VOICE COMMAND SYSTEM RUNNING

  2. Say Wake Word

    You: "Mantis"
    App: *** MANTIS DETECTED - 5s WINDOW ACTIVE ***

  3. Give Command (within 5 seconds)

    You: "Zoom in"
    App: [MATCH] ✓ Exact: "zoom in"
    App: [COMMAND] ✓ Sending: zoom_in
    App: [COMMAND] ✓ Success

  4. Window Expires (if no command given)

    App: *** WINDOW EXPIRED ***

Hot Reload Commands​

Reload command definitions without restarting:

# Get PID
cat /tmp/voice_command.pid

# Send reload signal
kill -USR2 $(cat /tmp/voice_command.pid)

# Or directly
killall -USR2 voice_command

The application will reload commands.json and keywords.txt and rebuild the grammar.

Command Matching Algorithm​

The application uses a two-stage matching process:

Stage 1: Exact Match​

  1. Normalize input (lowercase, trim)
  2. Remove filler words ("the", "a", "please", etc.)
  3. Compare with all command phrases
  4. Return match if found

Stage 2: Fuzzy Match (Levenshtein Distance)​

  1. Calculate edit distance for all phrases
  2. Allow up to 20% difference
  3. Return best match within tolerance

Example:

Input: "zom in pleas"
Normalized: "zom in"
Best Match: "zoom in" (distance: 1)
Threshold: 20% of 7 chars = 1.4
Result: MATCH ✓

Integration with Applications​

Command Server Implementation​

The voice command app sends commands to localhost:6975 by default. Implement a TCP server in your application to receive commands:

Python Example:

import socket
import threading

def command_handler(conn, addr):
    print(f"Connection from {addr}")
    while True:
        data = conn.recv(1024)
        if not data:
            break
        command = data.decode('utf-8').strip()
        print(f"Received command: {command}")

        # Process command
        if command == "zoom_in":
            print("Executing: Zoom In")
        elif command == "zoom_out":
            print("Executing: Zoom Out")
        elif command == "set_mode_black_hot":
            print("Executing: Black Hot Mode")
        elif command == "set_mode_white_hot":
            print("Executing: White Hot Mode")

    conn.close()

# Start server
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('127.0.0.1', 6975))
server.listen(5)
print("Command server listening on port 6975")

while True:
    conn, addr = server.accept()
    threading.Thread(target=command_handler, args=(conn, addr)).start()

C Example:

#include <sys/socket.h>
#include <netinet/in.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

int start_command_server(int port) {
    int server_fd, client_fd;
    struct sockaddr_in addr;
    char buffer[256];

    server_fd = socket(AF_INET, SOCK_STREAM, 0);
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(port);

    bind(server_fd, (struct sockaddr*)&addr, sizeof(addr));
    listen(server_fd, 5);

    printf("Command server listening on port %d\n", port);

    while (1) {
        client_fd = accept(server_fd, NULL, NULL);
        ssize_t n = recv(client_fd, buffer, sizeof(buffer)-1, 0);

        if (n > 0) {
            buffer[n] = '\0';
            printf("Received command: %s\n", buffer);

            // Process command
            if (strcmp(buffer, "zoom_in\n") == 0) {
                // Execute zoom in
            } else if (strcmp(buffer, "zoom_out\n") == 0) {
                // Execute zoom out
            }
        }

        close(client_fd);
    }

    return 0;
}

Troubleshooting​

No Audio Input​

# List ALSA devices
arecord -L

# Test recording
arecord -d 5 -f S16_LE -r 16000 -c 2 test.wav
aplay test.wav

# Use specific device
./voice_command --device plughw:1,0

Model Not Found​

ERROR: Failed to load model from /home/root/models/stt/vosk/vosk-model-small-en-us-0.15

Solution:

  • Verify model path exists: ls /home/root/models/stt/vosk/
  • Check model contents: ls /home/root/models/stt/vosk/vosk-model-small-en-us-0.15/am
  • Models are automatically installed via the vosk BitBake recipe
  • Available models: vosk-model-small-en-us-0.15 and vosk-model-en-us-0.22-lgraph

Poor Recognition Accuracy​

  • Use a larger Vosk model
  • Ensure quiet environment (reduce background noise)
  • Speak clearly and at normal pace
  • Update keywords.txt with your specific vocabulary
  • Adjust command phrases in commands.json

Command Server Connection Failed​

[TCP] Connection failed to 127.0.0.1:6975

Solution:

  • Ensure command server is running
  • Check port is not blocked: netstat -tulpn | grep 6975
  • Verify firewall settings

High CPU Usage​

  • Use smaller Vosk model (vosk-model-small-*)
  • Reduce audio buffer size in source code
  • Close other applications

Performance Notes​

Resource Usage​

On Sentinel SoM (ARM Cortex-A55):

  • CPU: ~30-40% (1 core) with small model
  • Memory: ~150MB RAM (model loaded)
  • Latency: ~100-200ms for recognition

Optimization Tips​

  1. Use Small Model: vosk-model-small-en-us-0.15 (~40MB)
  2. Reduce Audio Buffer: Lower frames_per_period in source
  3. Disable Partials: Modify source to skip partial results
  4. Optimize Commands: Reduce number of command phrases

System Integration​

Systemd Service​

Create /etc/systemd/system/voice-command.service:

[Unit]
Description=Voice Command Service
After=network.target sound.target

[Service]
Type=simple
User=root
WorkingDirectory=/usr/share/sentinel-sdk/voice_command
ExecStart=/usr/share/sentinel-sdk/voice_command/voice_command \
    --vosk-model /home/root/models/stt/vosk/vosk-model-small-en-us-0.15 \
    --device default \
    --command-host 127.0.0.1 \
    --command-port 6975
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

Enable and start:

sudo systemctl daemon-reload
sudo systemctl enable voice-command
sudo systemctl start voice-command
sudo systemctl status voice-command

Auto-Start on Boot​

Add to /etc/rc.local:

#!/bin/sh
cd /usr/share/sentinel-sdk/voice_command
./voice_command --vosk-model /home/root/models/stt/vosk/vosk-model-small-en-us-0.15 &
exit 0
