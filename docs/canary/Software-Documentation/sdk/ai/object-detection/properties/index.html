Properties

This page documents all configurable properties of the dctobd plugin element.

PropertyTypeDescriptionDefault
modelstringPath to the model file (.synap or .pt)NULL
model-directorystringDirectory to scan for available models/usr/share/synap/models
available-modelsstringList of available models (comma-separated)NULL (read-only)
labelstringPath to label/info JSON fileNULL
modestringPost-processing modeNULL
thresholdfloatConfidence threshold (0.0-1.0)0.5
numinferenceuintMaximum number of detections per frame5
frameintervaluintFrames to skip between inferences0
inferstatisticsbooleanEnable inference performance statisticsfalse
detection-enabledbooleanEnable or disable detectiontrue
enabled-classesstringList of enabled object classes (comma-separated)"person,car,bicycle"
available-classesstringList of available classes from model (comma-separated)NULL (read-only)

Property Details​

model​

Specifies the path to the object detection model file.

  • Type: String
  • Default: NULL
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd model=/usr/share/synap/models/yolov8s-640x384/model.synap ...
api_dctobd_set_model(<element_object>, "/usr/share/synap/models/yolov8s-640x384/model.synap");
g_object_set(<element_object>, "model", "/usr/share/synap/models/yolov8s-640x384/model.synap", NULL);
note

Model changes require pipeline restart to take effect.

model-directory​

Specifies the directory to scan for available model files.

  • Type: String
  • Default: "/usr/share/synap/models"
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd model-directory=/custom/models ...
api_dctobd_set_model_directory(<element_object>, "/custom/models");
g_object_set(<element_object>, "model-directory", "/custom/models", NULL);

available-models​

Returns the list of available model files found in the model directory.

  • Type: String (comma-separated list)
  • Default: NULL
  • Access: Read-only

Usage:

  • With API
  • GST API
char *models = api_dctobd_get_available_models(<element_object>);
if (models) {
    printf("Available models: %s\n", models);
    free(models);
}
gchar *models = NULL;
g_object_get(<element_object>, "available-models", &models, NULL);
if (models) {
    g_print("Available models: %s\n", models);
    g_free(models);
}

label​

Specifies the path to the label/info JSON file containing class labels.

  • Type: String
  • Default: NULL (falls back to /usr/share/synap/models/object_detection/coco/info.json)
  • Access: Read/Write

Usage:

  • Bash
  • GST API
gst-launch-1.0 ... ! dctobd label=/usr/share/synap/models/object_detection/coco/info.json ...
g_object_set(<element_object>, "label", "/path/to/labels.json", NULL);
note

Label file changes require pipeline restart to take effect. If not specified, the plugin uses a default label file path.

mode​

Specifies the post-processing mode for the model output.

  • Type: String
  • Default: NULL
  • Access: Read/Write
  • Valid values: "detector"

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd mode=detector ...
api_dctobd_set_mode(<element_object>, DCTOBD_MODE_DETECTOR);
g_object_set(<element_object>, "mode", "detector", NULL);

threshold​

Sets the confidence threshold for detections.

  • Type: Float (0.0 to 1.0)
  • Default: 0.5
  • Access: Read/Write

Only detections with confidence scores above this threshold will be reported. Lower values produce more detections but may include false positives.

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd threshold=0.7 ...
api_dctobd_set_confidence_threshold(<element_object>, 0.7f);
g_object_set(<element_object>, "threshold", 0.7f, NULL);

numinference​

Sets the maximum number of detections per frame.

  • Type: Integer (Unsigned)
  • Default: 5
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd numinference=10 ...
api_dctobd_set_max_detections(<element_object>, 10);
g_object_set(<element_object>, "numinference", 10, NULL);

frameinterval​

Sets the number of frames to skip between inferences.

  • Type: Integer (Unsigned)
  • Default: 0 (process every frame)
  • Access: Read/Write

Use this to reduce processing load by running inference on every Nth frame.

Usage:

  • Bash
  • With API
  • GST API
# Process every 3rd frame
gst-launch-1.0 ... ! dctobd frameinterval=3 ...
api_dctobd_set_frame_interval(<element_object>, 3);
g_object_set(<element_object>, "frameinterval", 3, NULL);

inferstatistics​

Enables logging of inference performance statistics.

  • Type: Boolean
  • Default: false
  • Access: Read/Write

Usage:

  • Bash
  • With API
  • GST API
gst-launch-1.0 ... ! dctobd inferstatistics=true ...
api_dctobd_set_inference_statistics(<element_object>, true);
g_object_set(<element_object>, "inferstatistics", TRUE, NULL);

detection-enabled​

Enables or disables object detection processing.

  • Type: Boolean
  • Default: true
  • Access: Read/Write

When disabled, frames pass through the element without any detection processing.

Usage:

  • Bash
  • With API
  • GST API
# Enable detection
gst-launch-1.0 ... ! dctobd detection-enabled=true ...

# Disable detection
gst-launch-1.0 ... ! dctobd detection-enabled=false ...
// Enable detection
api_dctobd_set_detection_enabled(<element_object>, true);

// Disable detection
api_dctobd_set_detection_enabled(<element_object>, false);
// Enable detection
g_object_set(<element_object>, "detection-enabled", TRUE, NULL);

// Disable detection
g_object_set(<element_object>, "detection-enabled", FALSE, NULL);

enabled-classes​

Specifies which object classes to detect.

  • Type: String (comma-separated class names)
  • Default: "person,car,bicycle"
  • Access: Read/Write

Set to a comma-separated list of class names to filter detections. Set to empty string or NULL to enable all classes.

Usage:

  • Bash
  • With API
  • GST API
# Detect only persons and cars
gst-launch-1.0 ... ! dctobd enabled-classes="person,car" ...

# Detect all vehicle types
gst-launch-1.0 ... ! dctobd enabled-classes="car,truck,bus,motorcycle" ...
// Detect only persons and cars
api_dctobd_set_enabled_classes(<element_object>, "person,car");

// Enable all classes
api_dctobd_set_enabled_classes(<element_object>, NULL);
// Detect only persons and cars
g_object_set(<element_object>, "enabled-classes", "person,car", NULL);

// Enable all classes
g_object_set(<element_object>, "enabled-classes", NULL, NULL);
note

Class names are case-sensitive and must match exactly as provided by the model.

available-classes​

Returns the list of classes supported by the loaded model.

  • Type: String (comma-separated class names)
  • Default: NULL
  • Access: Read-only

Query this property to see which object classes the current model can detect.

Usage:

  • With API
  • GST API
char *classes = api_dctobd_get_available_classes(<element_object>);
if (classes) {
    printf("Available classes: %s\n", classes);
    free(classes);
}
gchar *classes = NULL;
g_object_get(<element_object>, "available-classes", &classes, NULL);
if (classes) {
    g_print("Available classes: %s\n", classes);
    g_free(classes);
}
