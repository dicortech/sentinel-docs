Plugin Library

The Gstreamer plugin can be configured by changing its properties. Gstreamer provides a framework for achieving this, by using the g_object_set functions. We have also provided an API wrapper layer for specific use cases, which runs on top of the Gstreamer's APIs to achieve the same result.

The API definitions and their test codes can be found in the api/ directories:

inc/                   # Header files
├── gst/               # GStreamer layer (plugin interface)
├── mach/              # Machine layer (inference backends)
└── api/               # API layer (C interface)

src/                   # Source files
├── gst/               # GStreamer implementation
├── mach/              # Machine implementations (synap, torch, etc.)
└── api/               # API implementation

test/                  # Test applications
└── test_dctobd_api.cpp   # API-based test

Usage Flow​

To use the plugin library you will need to follow the below sequence of operations.

Step 1: Pipeline Initialization​

Initialize a gstreamer pipeline with this plugin.

#include <apidctobd.h>

GstElement *pipeline, *dctobd;

// Initialize
gst_init(&argc, &argv);
pipeline = gst_parse_launch("v4l2src ! videoconvert ! ... ! dctobd name=detector ! ...", NULL);
note

The plugin must have a name associated with it, which we will use to initialize the plugin api layer.

Step 2: Plugin Initialization​

Once the pipeline is initialized successfully, call the plugin initialization function to get the plugin element object.

  • With API
  • GST API
// Initialize
dctobd =api_dctobd_init(pipeline, "detector");
// Initialize
dctobd =gst_bin_get_by_name(pipeline, "detector");

Step 3: Plugin Configuration​

Once the initialization is done, you can use the apis as needed.

  • With API
  • GST API
// Configure
api_dctobd_set_model(dctobd, "/usr/share/synap/models/yolov8s-640x384/model.synap");
api_dctobd_set_mode(dctobd, DCTOBD_MODE_DETECTOR);
api_dctobd_set_output_mode(dctobd, OBD_OUTPUT_JSON);
api_dctobd_set_confidence_threshold(dctobd, 0.7f);
api_dctobd_set_enabled_classes(dctobd, "person,car");

// Optionally set label file (use GStreamer API for properties not in API layer)
g_object_set(dctobd, "label", "/path/to/labels.json", NULL);

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);
// Configure
g_object_set(dctobd,
            "model"           , "/usr/share/synap/models/yolov8s-640x384/model.synap",
            "label"           , "/path/to/labels.json",
            "mode"            , "detector",
            "output"          , "json",
            "threshold"       , 0.7f,
            "enabled-classes" , "person,car",
            NULL);

// Start pipeline
gst_element_set_state(pipeline, GST_STATE_PLAYING);

Custom DataTypes​

Dctobd Mode API​

Defines the detection mode for the dctobd element.

typedef enum {
    DCTOBD_MODE_DETECTOR = 0    // Detector mode for object detection
} DctobdModeAPI;
ValueDescription
DCTOBD_MODE_DETECTORObject detection mode

Functions​

These functions provide a C interface for controlling object detection from GStreamer pipelines.

api_dctobd_init​

Initialize and retrieve the dctobd element from a GStreamer pipeline.

GstElement* api_dctobd_init(GstElement *pipeline, const char *element_name);

Parameters:

  • pipeline - GstElement pipeline containing the dctobd element
  • element_name - Name of the dctobd element in the pipeline

Returns:

  • Pointer to dctobd element on success
  • NULL on failure
Memory Management

The caller is responsible for unreferencing the returned element using gst_object_unref() when done.

Example:

GstElement *pipeline = ...; // Your pipeline
GstElement *dctobd = api_dctobd_init(pipeline, "detector");
if (dctobd) {
    // Use the dctobd element
    gst_object_unref(dctobd);
}

api_dctobd_set_model​

Set the model file path.

bool api_dctobd_set_model(GstElement *element, const char *model_path);

Parameters:

  • element - dctobd GstElement
  • model_path - Path to the model file (.synap file)

Returns:

  • true on success
  • false on failure
note

Model changes require pipeline restart to take effect.

Example:

api_dctobd_set_model(dctobd, "/usr/share/synap/models/yolov8s-640x384/model.synap");

api_dctobd_set_model_directory​

Set the model directory for scanning.

bool api_dctobd_set_model_directory(GstElement *element, const char *directory);

Parameters:

  • element - dctobd GstElement
  • directory - Directory path to scan for models

Returns:

  • true on success
  • false on failure

Example:

api_dctobd_set_model_directory(dctobd, "/custom/models");

api_dctobd_get_available_models​

Get the list of available model files in the configured directory.

char* api_dctobd_get_available_models(GstElement *element);

Parameters:

  • element - dctobd GstElement

Returns:

  • Comma-separated list of model paths on success (caller must free())
  • NULL on failure
Memory Management

The caller must free() the returned string when done.

Example:

char *models = api_dctobd_get_available_models(dctobd);
if (models) {
    printf("Available models: %s\n", models);
    free(models);
}

api_dctobd_set_mode​

Set the detection mode.

bool api_dctobd_set_mode(GstElement *element, DctobdModeAPI mode);

Parameters:

  • element - dctobd GstElement
  • mode - Detection mode (currently only DCTOBD_MODE_DETECTOR is supported)

Returns:

  • true on success
  • false on failure

Example:

api_dctobd_set_mode(dctobd, DCTOBD_MODE_DETECTOR);

api_dctobd_set_confidence_threshold​

Set the confidence threshold for detections.

bool api_dctobd_set_confidence_threshold(GstElement *element, float threshold);

Parameters:

  • element - dctobd GstElement
  • threshold - Confidence threshold (0.0-1.0)

Returns:

  • true on success
  • false on failure

Example:

// Set threshold to 0.7 (70% confidence)
api_dctobd_set_confidence_threshold(dctobd, 0.7f);

api_dctobd_set_max_detections​

Set the maximum number of detections per frame.

bool api_dctobd_set_max_detections(GstElement *element, int num_inference);

Parameters:

  • element - dctobd GstElement
  • num_inference - Maximum number of detections per frame

Returns:

  • true on success
  • false on failure

Example:

api_dctobd_set_max_detections(dctobd, 10);

api_dctobd_set_frame_interval​

Set the frame processing interval.

bool api_dctobd_set_frame_interval(GstElement *element, int interval);

Parameters:

  • element - dctobd GstElement
  • interval - Process every Nth frame (0 = process all frames)

Returns:

  • true on success
  • false on failure

Example:

// Process every 3rd frame
api_dctobd_set_frame_interval(dctobd, 3);

api_dctobd_set_inference_statistics​

Enable or disable inference statistics.

bool api_dctobd_set_inference_statistics(GstElement *element, bool enable);

Parameters:

  • element - dctobd GstElement
  • enable - true to enable statistics, false to disable

Returns:

  • true on success
  • false on failure

Example:

api_dctobd_set_inference_statistics(dctobd, true);

api_dctobd_set_detection_enabled​

Enable or disable object detection.

bool api_dctobd_set_detection_enabled(GstElement *element, bool enable);

Parameters:

  • element - dctobd GstElement
  • enable - true to enable detection, false to disable

Returns:

  • true on success
  • false on failure

Example:

// Disable detection
api_dctobd_set_detection_enabled(dctobd, false);

// Enable detection
api_dctobd_set_detection_enabled(dctobd, true);

api_dctobd_set_enabled_classes​

Set the enabled class names for filtering.

bool api_dctobd_set_enabled_classes(GstElement *element, const char *classes);

Parameters:

  • element - dctobd GstElement
  • classes - Comma-separated list of class names to enable

Returns:

  • true on success
  • false on failure
note

If NULL or empty, all classes are enabled.

Example:

// Detect only persons and cars
api_dctobd_set_enabled_classes(dctobd, "person,car");

// Enable all classes
api_dctobd_set_enabled_classes(dctobd, NULL);

Usage Example​

Here's a complete example demonstrating the API usage:

#include "apidctobd.h"

int main(int argc, char *argv[])
{
    GstElement *pipeline, *dctobd;

    // Initialize pipeline
    gst_init(&argc, &argv);
    pipeline = gst_parse_launch(
        "v4l2src device=/dev/video8 ! videoconvert ! videoscale ! "
        "video/x-raw,width=640,height=384,format=RGB ! "
        "dctobd name=detector ! "
        "dctobdsink location=/tmp/results.txt",
        NULL);

    // Get dctobd element
    dctobd = api_dctobd_init(pipeline, "detector");
    if (!dctobd) {
        fprintf(stderr, "Failed to initialize dctobd element\n");
        return -1;
    }

    // Configure for person detection
    api_dctobd_set_model(dctobd, "/usr/share/synap/models/yolov8s-640x384/model.synap");
    api_dctobd_set_mode(dctobd, DCTOBD_MODE_DETECTOR);
    api_dctobd_set_output_mode(dctobd, OBD_OUTPUT_JSON);
    api_dctobd_set_confidence_threshold(dctobd, 0.7f);
    api_dctobd_set_enabled_classes(dctobd, "person");
    api_dctobd_set_frame_interval(dctobd, 3);

    // Start pipeline
    gst_element_set_state(pipeline, GST_STATE_PLAYING);

    // Run main loop...

    // Later: query available classes
    char *classes = api_dctobd_get_available_classes(dctobd);
    if (classes) {
        g_print("Available classes: %s\n", classes);
        free(classes);
    }

    // Switch to vehicle detection
    api_dctobd_set_enabled_classes(dctobd, "car,truck,bus,motorcycle");
    api_dctobd_set_confidence_threshold(dctobd, 0.6f);

    // Cleanup
    gst_object_unref(dctobd);

    return 0;
}
